## 7. Python Standard Library Overview 

### What is the standard library?
The **standard library** is the collection of modules that come **built into Python**. You don't need to install anything with pip to use them. We have already used several of them in earlier modules.

Real-life comparison: a **kitchen that already has a stove, a fridge and basic utensils**. You don't need to buy them before cooking. You can add extra specialised equipment later with pip.

### Modules you have already met
- `math`, `random`: maths and random numbers
- `json`, `csv`: reading and writing data files
- `datetime`: dates and times
- `os`, `pathlib`: working with files, folders and environment variables
- `logging`: recording messages
- `unittest`: testing (covered in Module 10)
- `dataclasses`, `functools`, `copy`, `gc`: advanced tools from earlier modules

### A quick tour of useful modules

- **`sys`**: information about the interpreter, such as `sys.argv` and `sys.version`
- **`collections`**: special containers like `Counter`, `defaultdict` and `deque`
- **`itertools`**: tools for looping in clever ways
- **`statistics`**: mean, median and mode
- **`string`**: useful string constants and helpers
- **`time`**: timing and pausing a program
- **`urllib`**: basic web requests (`requests` from pip is more popular)
- **`sqlite3`**: a built-in lightweight database
- **`argparse`**: command-line arguments (Module 2)
- **`venv`**: creating virtual environments
- **`pdb`**: the debugger (Module 7)

### Examples
```python
from collections import Counter

words = ["python", "is", "fun", "python", "is", "great", "python"]
print(Counter(words))              # Counter({'python': 3, 'is': 2, 'fun': 1, 'great': 1})
print(Counter(words).most_common(1))   # [('python', 3)]
```

```python
import statistics

marks = [78, 92, 65, 88, 92]
print(statistics.mean(marks))      # 83
print(statistics.median(marks))    # 88
print(statistics.mode(marks))      # 92
```

```python
import sqlite3

conn = sqlite3.connect("school.db")
cur = conn.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS students (name TEXT, marks INTEGER)")
cur.execute("INSERT INTO students VALUES ('Asha', 85)")
conn.commit()
conn.close()
```

```python
from collections import defaultdict

groups = defaultdict(list)
for name, dept in [("Asha", "IT"), ("Ravi", "HR"), ("Meena", "IT")]:
    groups[dept].append(name)

print(dict(groups))    # {'IT': ['Asha', 'Meena'], 'HR': ['Ravi']}
```

### Finding help
```python
import collections
print(dir(collections))            # every name inside the module
help(collections.Counter)          # detailed help
```
The official documentation at docs.python.org has the full list.

### Why use the standard library first?
- It is already installed everywhere Python is.
- It is tested and maintained by the Python team.
- It keeps `requirements.txt` short.

Check the standard library **before** installing a third-party package. You may already have what you need.
