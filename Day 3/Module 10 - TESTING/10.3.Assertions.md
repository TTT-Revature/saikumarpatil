## 3. Assertions and Testing Exceptions

### Assertions: checking results
We saw in Module 7 that `assert` checks a condition inside your code. In tests, assertions are how you check results. Using `unittest`'s methods gives you **better error messages** than a plain `assert`.

```python
import unittest

class TestExample(unittest.TestCase):
    def test_with_plain_assert(self):
        assert 2 + 2 == 5       # the message is just "AssertionError"

    def test_with_unittest_assert(self):
        self.assertEqual(2 + 2, 5)   # shows: AssertionError: 4 != 5
```

### Testing that an exception is raised
Sometimes the correct behaviour is to **raise an error**. Use `assertRaises` to check that it happens.

```python
import unittest

def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("Cannot divide by zero")
    return a / b

class TestDivide(unittest.TestCase):
    def test_divide_by_zero_raises_error(self):
        with self.assertRaises(ZeroDivisionError):
            divide(10, 0)

    def test_divide_normal(self):
        self.assertEqual(divide(10, 2), 5)
```

### Checking the exception message
Use `assertRaises` as a context manager, and inspect the captured error:
```python
def test_error_message(self):
    with self.assertRaises(ZeroDivisionError) as context:
        divide(10, 0)
    self.assertIn("Cannot divide", str(context.exception))
```

### Testing that no exception is raised
A test that runs without error passes. For clarity, some people write it explicitly:
```python
def test_valid_input_does_not_crash(self):
    try:
        result = divide(10, 5)
    except ZeroDivisionError:
        self.fail("divide should not raise for valid input")
    self.assertEqual(result, 2)
```

### Real-time example: validating an age function
```python
import unittest

def set_age(age):
    if not isinstance(age, int):
        raise TypeError("Age must be a whole number")
    if age < 0:
        raise ValueError("Age cannot be negative")
    return age

class TestSetAge(unittest.TestCase):
    def test_valid_age(self):
        self.assertEqual(set_age(21), 21)

    def test_negative_age_raises_value_error(self):
        with self.assertRaises(ValueError):
            set_age(-1)

    def test_text_age_raises_type_error(self):
        with self.assertRaises(TypeError):
            set_age("twenty")
```

> **Trainer tip:** A common student mistake is writing a test that never fails, such as `assertTrue(True)`. Ask students: "How would this test fail if the function were broken?" If the answer is "it wouldn't", the test is useless.
