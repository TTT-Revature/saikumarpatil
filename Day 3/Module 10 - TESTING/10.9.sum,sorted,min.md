## 9. `sum()`, `sorted()`, `min()`, `max()` and `reversed()` 

These built-in functions cover the most common data tasks. Many of them work on any iterable, including lists, tuples, sets and generators.

### `sum()`: add up the values
```python
prices = [120, 45, 300]
print(sum(prices))                    # 465
print(sum(prices, 100))               # 565   (start the total at 100)
print(sum(x * x for x in range(4)))   # 14    (0 + 1 + 4 + 9)
```

### `min()` and `max()`: smallest and largest
```python
marks = [72, 95, 60]
print(min(marks))                     # 60
print(max(marks))                     # 95
```

With a key function, you can compare by a rule:
```python
students = [("Asha", 85), ("Ravi", 62), ("Meena", 92)]
print(max(students, key=lambda s: s[1]))    # ('Meena', 92)
```

Both work on an empty list only with a `default`:
```python
print(max([], default="nothing"))     # nothing
```

### `sorted()`: a new sorted list
`sorted()` returns a **new list** and leaves the original unchanged (Module 4).

```python
marks = [72, 95, 60]
ranking = sorted(marks, reverse=True)
print(ranking)                        # [95, 72, 60]
print(marks)                          # [72, 95, 60]  (unchanged)
```

Sorting by a rule:
```python
students = [("Asha", 85), ("Ravi", 62), ("Meena", 92)]
by_marks = sorted(students, key=lambda s: s[1], reverse=True)
print(by_marks)
# [('Meena', 92), ('Asha', 85), ('Ravi', 62)]
```

### `reversed()`: walk backwards without copying
`reversed()` gives an iterator that walks from the end. It does not create a new list.

```python
letters = ["a", "b", "c"]
for letter in reversed(letters):
    print(letter)
```
```
c
b
a
```

Wrap it in `list()` if you need to see all items at once:
```python
print(list(reversed(letters)))        # ['c', 'b', 'a']
```

Compare with slicing, which creates a copy:
```python
print(letters[::-1])                  # ['c', 'b', 'a']  (new list)
```

### Combining them: a leaderboard
```python
scores = {"Asha": 85, "Ravi": 62, "Meena": 92, "Kumar": 78}

ranking = sorted(scores.items(), key=lambda item: item[1], reverse=True)

for position, (name, score) in enumerate(ranking, start=1):
    print(f"{position}. {name} - {score}")

print("Average:", sum(scores.values()) / len(scores))
print("Top score:", max(scores.values()))
```
```
1. Meena - 92
2. Asha - 85
3. Kumar - 78
4. Ravi - 62
Average: 79.25
Top score: 92
```

### Choosing the right tool
- Need the total? `sum()`
- Need a new ordered copy? `sorted()`
- Need the largest or smallest by a rule? `max()` or `min()` with `key`
- Need to walk backwards efficiently? `reversed()`
