## 8. `enumerate()`, `zip()`, `any()` and `all()`

These built-in functions help you write clear, Pythonic loops and checks. They are self-read, but practise them with the examples below.

### `enumerate()`: get the index and the value together
Instead of managing a counter yourself, `enumerate()` gives you both.

```python
fruits = ["apple", "banana", "mango"]

# the manual way
i = 0
for fruit in fruits:
    print(i, fruit)
    i += 1

# the Pythonic way
for i, fruit in enumerate(fruits):
    print(i, fruit)
```
```
0 apple
1 banana
2 mango
```

Start counting from a different number with `start`:
```python
for rank, name in enumerate(["Asha", "Ravi", "Meena"], start=1):
    print(f"{rank}. {name}")
```
```
1. Asha
2. Ravi
3. Meena
```

### `zip()`: combine lists side by side
`zip()` pairs items from two or more lists, one from each list at a time.

```python
names = ["Asha", "Ravi", "Meena"]
marks = [85, 72, 90]

for name, mark in zip(names, marks):
    print(f"{name}: {mark}")
```
```
Asha: 85
Ravi: 72
Meena: 90
```

Creating a dictionary from two lists:
```python
result = dict(zip(names, marks))
print(result)          # {'Asha': 85, 'Ravi': 72, 'Meena': 90}
```

> **Careful:** `zip()` stops at the **shortest** list. Extra items in the longer list are ignored.

### `any()`: is at least one item True?
```python
marks = [35, 72, 48]
print(any(m >= 90 for m in marks))    # False  (nobody got 90+)
print(any(m >= 70 for m in marks))    # True   (at least one got 70+)
```

### `all()`: are ALL items True?
```python
marks = [35, 72, 48]
print(all(m >= 40 for m in marks))    # False  (35 is below 40)
print(all(m >= 30 for m in marks))    # True
```

Empty lists are special:
```python
print(any([]))    # False   (no item is True)
print(all([]))    # True    (no item is False)
```

### Real-time example: validating a form
```python
fields = {"name": "Asha", "email": "asha@mail.com", "phone": ""}

if all(value.strip() for value in fields.values()):
    print("All fields are filled")
else:
    print("Please fill every field")
```

### Real-time example: checking a password
```python
password = "Python123"

has_digit = any(ch.isdigit() for ch in password)
has_upper = any(ch.isupper() for ch in password)
long_enough = len(password) >= 8

print(all([has_digit, has_upper, long_enough]))    # True
```
