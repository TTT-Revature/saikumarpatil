## 3. String Methods

### Function vs method
- A **function** works with **any** data type. Example: `print()`, `len()`, `type()`.
- A **method** works **only on a particular data type** and is called using a dot. Example: `"hello".upper()` is a **string method**, and `my_list.append(5)` is a **list method**.

```python
s = "python"
s.upper()      # method (dot notation)
len(s)         # function
```

> **Very important:** Strings are **immutable**, so string methods **never change the original string**. They **return a new string**. You must **store the result** if you want to keep it.
> ```python
> s = "python"
> s.upper()
> print(s)        # python  (unchanged!)
>
> s = s.upper()
> print(s)        # PYTHON  (now stored)
> ```

To see every method available on strings:
```python
print(dir(str))
```

### Changing case

**`upper()`** converts all characters to uppercase.
```python
s = "hello world"
print(s.upper())        # HELLO WORLD
```

**`lower()`** converts all characters to lowercase.
```python
s = "HELLO World"
print(s.lower())        # hello world
```

**`capitalize()`** returns a copy with the **first letter capital** and **all the remaining letters in lowercase**.
```python
s = "hello World"
print(s.capitalize())   # Hello world
```

**`title()`** makes the **first letter of every word** capital.
```python
s = "good morning everyone"
print(s.title())        # Good Morning Everyone
```

**`swapcase()`** converts small letters to capital and capital to small (vice versa).
```python
s = "hEllo 2 WORLd"
print(s.swapcase())     # HeLLO 2 worlD
```

### Removing spaces

**`strip()`** removes spaces from **both** the start and the end.
```python
s = "   Python   "
print(s.strip())        # 'Python'
```

**`lstrip()`** removes spaces from the **left (start)** only.
```python
s = "   Python"
print(s.lstrip())       # 'Python'
```

**`rstrip()`** removes spaces from the **right (end)** only.
```python
s = "Python   "
print(s.rstrip())       # 'Python'
```

> **Note:** `strip()` only removes spaces at the **edges**, never in the middle.
> ```python
> print("  Sai  Kumar  ".strip())     # 'Sai  Kumar'
> ```
> You can also strip specific characters: `"***hi***".strip("*")` gives `'hi'`.

### Searching

**`find()`** returns the **index of the first match**, or **-1** if not found.
```python
s = "hello world"
print(s.find("o"))        # 4
print(s.find("world"))    # 6
print(s.find("xyz"))      # -1
```

**`index()`** is like `find()` but raises a **ValueError** if the text isn't found.

**`count()`** tells **how many times** something appears.
```python
s = "banana"
print(s.count("a"))       # 3
```

**`startswith()` and `endswith()`** check the beginning and end.
```python
file = "report.pdf"
print(file.startswith("rep"))    # True
print(file.endswith(".pdf"))     # True
```

### Checking the type of content
```python
print("Python".isalpha())       # True
print("2025".isdigit())         # True
print("abc123".isalnum())       # True
print("hello".islower())        # True
print("HELLO".isupper())        # True
print("Hello World".istitle())  # True
```

### Aligning and filling
```python
print("7".zfill(3))             # 007
print("Hi".center(10, "*"))     # ****Hi****
print("Hi".ljust(6, "."))       # Hi....
print("Hi".rjust(6, "."))       # ....Hi
```

### Real-time example: cleaning user input
```python
raw = "   sAi KuMAR   "
clean = raw.strip().title()
print(clean)      # Sai Kumar
```
You can **chain** methods, and they work from left to right.

### Real-time example: simple username check
```python
username = input("Enter username: ").strip().lower()

if username.isalnum():
    print("Valid username")
else:
    print("Only letters and numbers allowed")
```
