## 9. Groups and Practical Patterns

### What is a group?
A **group** is a part of the pattern wrapped in **round brackets `( )`**. Groups let you:
1. **Extract a specific part** of a match
2. **Apply a quantifier** to several characters at once
3. **Use OR** inside a small portion of the pattern

Real-life example: a phone number like `044-23456789`. The whole thing is one match, but you may want the **area code** and the **number** separately. Groups let you grab each part.

### Capturing groups
```python
import re

text = "Date: 2025-01-15"
match = re.search(r"(\d{4})-(\d{2})-(\d{2})", text)

print(match.group())     # 2025-01-15   (the whole match)
print(match.group(1))    # 2025         (first group)
print(match.group(2))    # 01           (second group)
print(match.group(3))    # 15           (third group)
print(match.groups())    # ('2025', '01', '15')
```
- `group(0)` or `group()` → the **entire** match
- `group(1)`, `group(2)` ... → each bracketed part, **numbered from left to right**

### Named groups (easier to read)
Use `(?P<name>...)`.
```python
match = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", "Date: 2025-01-15")

print(match.group("year"))     # 2025
print(match.group("month"))    # 01
print(match.groupdict())       # {'year': '2025', 'month': '01', 'day': '15'}
```

### Groups with OR
```python
print(re.findall(r"(Mr|Mrs|Ms)\. \w+", "Mr. Kumar and Mrs. Devi"))
# ['Mr', 'Mrs']      (findall returns the group when groups exist)
```

### Groups with quantifiers
```python
print(re.search(r"(ab)+", "ababab").group())     # ababab
```
Here `+` applies to the whole `ab`, not just `b`.

### Non-capturing groups `(?: )`
Use these when you need grouping but **don't want to capture** the text.
```python
print(re.findall(r"(?:Mr|Mrs|Ms)\. \w+", "Mr. Kumar and Mrs. Devi"))
# ['Mr. Kumar', 'Mrs. Devi']
```

### Practical patterns library

**1. Email validation (simple)**
```python
pattern = r"^[\w\.-]+@[\w\.-]+\.\w{2,}$"
print(bool(re.match(pattern, "sai.kumar@gmail.com")))    # True
print(bool(re.match(pattern, "sai@@gmail")))             # False
```

**2. Indian mobile number**
```python
pattern = r"^[6-9]\d{9}$"
print(bool(re.match(pattern, "9876543210")))    # True
print(bool(re.match(pattern, "1234567890")))    # False
```

**3. Date in DD-MM-YYYY**
```python
pattern = r"\b(\d{2})-(\d{2})-(\d{4})\b"
text = "Born on 15-08-1999, joined on 01-06-2023"
print(re.findall(pattern, text))
# [('15', '08', '1999'), ('01', '06', '2023')]
```

**4. Extracting hashtags**
```python
tweet = "Loving #Python and #AI today! #coding"
print(re.findall(r"#\w+", tweet))     # ['#Python', '#AI', '#coding']
```

**5. Simple strong password (min 8 characters, with letter and digit)**
```python
pattern = r"^(?=.*[A-Za-z])(?=.*\d).{8,}$"
print(bool(re.match(pattern, "python123")))   # True
print(bool(re.match(pattern, "python")))      # False
```
This uses **lookaheads** `(?=...)`, an advanced feature that checks conditions without consuming the text. Just treat it as a ready-made recipe for now.

> **Tip for students:** Build regex **step by step**. Start with a small pattern, test it, then extend it. Websites like **regex101.com** let you test patterns and explain each part visually.
