## 11. `re.findall()` and `re.sub()` 

### `re.findall()`: find ALL matches
`re.search()` gives only the first match. `re.findall()` gives **every match as a list**.

**Syntax:**
```python
re.findall(pattern, text)
```

```python
import re

text = "Ravi: 9876543210, Asha: 9123456780, Meena: 9988776655"

numbers = re.findall(r"\d{10}", text)
print(numbers)
# ['9876543210', '9123456780', '9988776655']
```

If nothing matches, you get an **empty list** `[]` (not an error).
```python
print(re.findall(r"\d+", "no digits"))     # []
```

**Extracting all words that start with a capital letter:**
```python
text = "Sai went to Chennai with Asha"
print(re.findall(r"[A-Z]\w*", text))       # ['Sai', 'Chennai', 'Asha']
```

**Extracting all email addresses:**
```python
text = "Contact sai@gmail.com, support@company.in or hr@firm.org"
print(re.findall(r"[\w\.-]+@[\w\.-]+\.\w+", text))
# ['sai@gmail.com', 'support@company.in', 'hr@firm.org']
```

**Behaviour with groups:** if your pattern has **groups**, `findall()` returns the **groups**, not the full match.
```python
print(re.findall(r"(\w+)@(\w+)\.com", "sai@gmail.com asha@yahoo.com"))
# [('sai', 'gmail'), ('asha', 'yahoo')]
```

### `re.finditer()`: matches one by one with positions
```python
for m in re.finditer(r"\d+", "a1 b22 c333"):
    print(m.group(), m.span())
```
```
1 (1, 2)
22 (4, 6)
333 (8, 11)
```

### `re.sub()`: search and REPLACE using a pattern
This is the **pattern-based version of `replace()`**.

**Syntax:**
```python
re.sub(pattern, replacement, text)
re.sub(pattern, replacement, text, count=n)    # limit replacements
```

**Hiding digits:**
```python
text = "My PIN is 4821 and OTP is 937562"
print(re.sub(r"\d", "*", text))
# My PIN is **** and OTP is ******
```

**Removing extra spaces:**
```python
text = "Python    is     easy"
print(re.sub(r"\s+", " ", text))       # Python is easy
```

**Removing special characters (text cleaning for AI/NLP):**
```python
text = "Hello!!! How are you?? #Python @2025"
clean = re.sub(r"[^A-Za-z0-9 ]", "", text)
print(clean)        # Hello How are you Python 2025
```

**Masking a phone number (keep the last 4 digits):**
```python
phone = "9876543210"
print(re.sub(r"\d(?=\d{4})", "X", phone))      # XXXXXX3210
```

**Using groups in the replacement (`\1`, `\2`):** change a date format from `YYYY-MM-DD` to `DD-MM-YYYY`:
```python
date = "2025-01-15"
print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3-\2-\1", date))
# 15-01-2025
```
`\1`, `\2`, `\3` refer to the first, second and third groups.

**Limiting replacements:**
```python
print(re.sub(r"a", "@", "banana", count=2))    # b@n@na
```

### `re.split()`: split by a pattern
Split when there may be **many different separators**:
```python
text = "apple, banana;mango  orange"
print(re.split(r"[,; ]+", text))
# ['apple', 'banana', 'mango', 'orange']
```

### `re.compile()`: reuse a pattern
If you use the same pattern many times, compile it once:
```python
pattern = re.compile(r"\d{10}")

print(pattern.findall("9876543210 and 9123456780"))
print(pattern.search("Call 9876543210"))
```

### Real-time example: a mini log analyser
```python
import re

log = """
2025-01-15 ERROR Disk full
2025-01-15 INFO Backup done
2025-01-16 ERROR Network down
"""

errors = re.findall(r"(\d{4}-\d{2}-\d{2}) ERROR (.+)", log)
for date, message in errors:
    print(f"{date}: {message}")
```
```
2025-01-15: Disk full
2025-01-16: Network down
```

### Real-time example: cleaning social media text
```python
tweet = "Loving #Python!!! Visit https://example.com NOW "

tweet = re.sub(r"https?://\S+", "", tweet)      # remove links
tweet = re.sub(r"[^A-Za-z0-9#\s]", "", tweet)   # remove special characters
tweet = re.sub(r"\s+", " ", tweet).strip()      # fix extra spaces

print(tweet)      # Loving #Python Visit NOW
```
