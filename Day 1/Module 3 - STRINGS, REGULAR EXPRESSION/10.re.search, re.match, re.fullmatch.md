## 10. `re.search()`, `re.match()`, `re.fullmatch()` 

These three functions check **whether a pattern appears in a text**. The difference is **where** they look.

Real-life example: you are looking for the word "Python" in a sentence.
- `re.match()`: "Does the sentence **start with** Python?"
- `re.search()`: "Is Python **anywhere** in the sentence?"
- `re.fullmatch()`: "Is the **entire sentence exactly** Python?"

**Syntax (same for all three):**
```python
re.function(pattern, text)
```
They return a **match object** if found, or **`None`** if not.

### `re.match()`: only at the START
```python
import re

print(re.match(r"Python", "Python is easy"))     # match
print(re.match(r"easy", "Python is easy"))       # None  (not at the start)
```

### `re.search()`: anywhere (finds the FIRST match)
```python
print(re.search(r"easy", "Python is easy"))      # match
print(re.search(r"Java", "Python is easy"))      # None
```
`re.search()` stops after the **first** match. If the pattern appears 5 times, you get only the first.

### `re.fullmatch()`: the WHOLE string must match
```python
print(re.fullmatch(r"\d{10}", "9876543210"))        # match
print(re.fullmatch(r"\d{10}", "9876543210 abc"))    # None  (extra text)
print(re.fullmatch(r"\d{10}", "98765"))             # None  (too short)
```

### Side-by-side comparison
```python
text = "Python is easy"

print(re.match(r"is", text))         # None   (text doesn't START with 'is')
print(re.search(r"is", text))        # match  (found inside)
print(re.fullmatch(r"is", text))     # None   (whole text isn't 'is')
```

### Reading the match object
A match object holds useful information:
```python
m = re.search(r"\d+", "Order number 4521 shipped")

print(m)             # <re.Match object; span=(13, 17), match='4521'>
print(m.group())     # 4521     (the matched text)
print(m.start())     # 13       (start index)
print(m.end())       # 17       (end index, excluded)
print(m.span())      # (13, 17)
```

### Always check for `None` before using the result
If there's no match, `None.group()` would crash the program:
```python
m = re.search(r"\d+", "No numbers here")
print(m.group())      # AttributeError: 'NoneType' object has no attribute 'group'
```
Safe way:
```python
m = re.search(r"\d+", "No numbers here")

if m:
    print("Found:", m.group())
else:
    print("No match")
```

### Real-time example: input validation
```python
import re

mobile = input("Enter mobile number: ")

if re.fullmatch(r"[6-9]\d{9}", mobile):
    print("Valid number")
else:
    print("Invalid number")
```
`re.fullmatch()` is perfect for validation, because the **entire** input must follow the rule.

### Which one should I use?
- Need to **find something anywhere**? → `re.search()`
- Need to check the **beginning** only? → `re.match()`
- Need to **validate the whole input**? → `re.fullmatch()`

### Flags: ignoring case
```python
print(re.search(r"python", "I love PYTHON", re.IGNORECASE))    # match
```
The short form is `re.I`.
