## 4. `split()`, `join()`, `replace()`, `strip()`

These four methods are the **everyday tools** for processing text. You will use them constantly in data cleaning and AI/NLP work.

### `split()`: break a string into a LIST of parts

`split()` cuts a string into pieces at a **delimiter** (separator) and returns a **list**.

- Whatever you give as the delimiter is **not included** in the output.
- If you give **no delimiter**, it splits at **spaces** (and handles extra spaces too).

```python
s = "Sai Kumar Patil"
print(s.split())             # ['Sai', 'Kumar', 'Patil']
```
```python
data = "apple,banana,mango"
print(data.split(","))       # ['apple', 'banana', 'mango']
```
```python
date = "2025-01-15"
year, month, day = date.split("-")
print(year, month, day)      # 2025 01 15
```

**Limit the number of splits:**
```python
s = "a-b-c-d"
print(s.split("-", 2))       # ['a', 'b', 'c-d']
```

### `join()`: combine a list of strings into ONE string

`join()` is the **opposite of split**. It joins a list of strings into a single string using a **delimiter** (the character in front of `.join`).

**Syntax:**
```python
"delimiter".join([s1, s2, s3])
```

```python
words = ["Sai", "Kumar", "Patil"]
print(" ".join(words))       # Sai Kumar Patil
print("-".join(words))       # Sai-Kumar-Patil
print("".join(words))        # SaiKumarPatil
```

> **Important:** `join()` works only on a list of **strings**. For numbers, convert them first:
> ```python
> nums = [1, 2, 3]
> print(",".join(str(n) for n in nums))     # 1,2,3
> ```

### `replace()`: swap old text with new text

**Syntax:**
```python
string.replace(old, new)
string.replace(old, new, count)      # count = how many to replace
```

```python
s = "I like Java. Java is great."
print(s.replace("Java", "Python"))       # I like Python. Python is great.
print(s.replace("Java", "Python", 1))    # I like Python. Java is great.
```

Removing text by replacing with an empty string:
```python
phone = "98-76-54-32-10"
print(phone.replace("-", ""))            # 9876543210
```

### `strip()`: trim the edges
```python
print("  hello  ".strip())      # 'hello'
```

### Using them together: a mini cleaning pipeline
```python
raw = "  Chennai, Mumbai , Delhi,  Pune  "

cities = [city.strip() for city in raw.split(",")]
print(cities)                   # ['Chennai', 'Mumbai', 'Delhi', 'Pune']

print(" | ".join(cities))       # Chennai | Mumbai | Delhi | Pune
```

### Real-time example: word counter
```python
sentence = "python is easy and python is powerful"
words = sentence.split()

print("Total words:", len(words))              # 7
print("'python' appears:", words.count("python"))   # 2
```

### Real-time example: make a URL-friendly name
```python
title = "My First Python Program"
slug = title.lower().replace(" ", "-")
print(slug)      # my-first-python-program
```
