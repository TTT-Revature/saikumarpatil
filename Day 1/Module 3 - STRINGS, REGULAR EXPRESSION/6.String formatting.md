## 6. String Formatting

String formatting means **inserting values into a string** neatly. There are three ways. The first one is the best.

### 1. f-strings (recommended, Python 3.6+)
Put `f` before the string and write variables inside `{ }`.
```python
name = "Asha"
age = 21
print(f"My name is {name} and I am {age} years old")
```
You can put **expressions** inside as well:
```python
price = 250
qty = 3
print(f"Total = {price * qty}")      # Total = 750
```

**Number formatting:**
```python
pi = 3.14159265
print(f"{pi:.2f}")          # 3.14        (2 decimal places)
print(f"{1500000:,}")       # 1,500,000   (thousands separator)
print(f"{0.856:.1%}")       # 85.6%       (percentage)
print(f"{7:03}")            # 007         (leading zeros)
```

**Alignment:**
```python
print(f"{'Name':<10}{'Marks':>6}")
print(f"{'Asha':<10}{85:>6}")
```
- `<` left, `>` right, `^` centre. The number is the total width.

### 2. `.format()` method
Use `{}` as placeholders and fill them with `.format()`.
```python
print("My name is {} and I am {}".format("Asha", 21))
print("My name is {0} and I am {1}".format("Asha", 21))
print("My name is {n} and I am {a}".format(n="Asha", a=21))
```

### 3. `%` formatting (oldest, seen in old code)
```python
print("My name is %s and I am %d" % ("Asha", 21))
print("Price: %.2f" % 99.5)
```
- `%s` for string, `%d` for integer, `%f` for float.

### Which one should you use?
- **f-strings** for all new code (clean and fast).
- Know `.format()` and `%` so you can **read older code**.

### Real-time example: a result card
```python
name = "Ravi"
maths, science, english = 88, 92, 79
total = maths + science + english
percentage = total / 300 * 100

print("=" * 28)
print(f"Student    : {name}")
print(f"Total      : {total}/300")
print(f"Percentage : {percentage:.2f}%")
print("=" * 28)
```
