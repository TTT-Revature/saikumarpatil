## 1. Creating and Working with Strings 📖 (Self-read)

### What is a string?
A **string** (`str`) is a **sequence of characters**: letters, numbers, spaces and special symbols, all treated as **text**. Even though it contains many characters, a string is stored as a **single value**.

Real-life example: your name, your phone number written on a form, your address and a WhatsApp message are all strings.

### Creating strings
You can use **single**, **double** or **triple** quotes.

```python
name = 'Siva'
city = "Chennai"
message = '''This is
a multi-line string'''
```

All three work the same way for normal text. The rule is: **non-numeric data must always be inside quotes**.

```python
a = "Siva123"      # text with numbers
b = "Siva-123"     # text with special characters
c = "?"            # only a special character
d = "123"          # this is TEXT, not a number!
```

> **Careful:** `123` (no quotes) is an `int`, but `"123"` (with quotes) is a `str`.

### Quotes inside quotes
```python
print("It's a sunny day")          # single quote inside double quotes
print('He said "Hello"')           # double quotes inside single quotes
```

### Checking length with `len()`
`len()` counts **how many characters** are in the string, including spaces.
```python
s = "Data Science"
print(len(s))     # 12
```

### Joining strings (concatenation) and repeating
```python
first = "Sai"
last = "Kumar"

print(first + " " + last)    # Sai Kumar    (concatenation with +)
print("Ha" * 3)              # HaHaHa       (repetition with *)
print("-" * 20)              # --------------------
```

> **Note:** You can only `+` a string with another **string**. `"Age: " + 25` gives a `TypeError`. Use `str(25)` or an f-string.

### Looping through a string
```python
for ch in "SIVA":
    print(ch)
```

### Checking inside a string
```python
print("Sai" in "Sai Kumar")      # True
print("xyz" not in "Sai Kumar")  # True
```

### Strings are immutable
A string **cannot be changed in place**. Once created, you can't edit a single character.
```python
name = "Sai"
# name[0] = "R"     # TypeError: 'str' object does not support item assignment

name = "R" + name[1:]   # build a NEW string instead
print(name)             # Rai
```

### Converting between strings and numbers
A string can be converted to a number **only if it looks like a number**.
```python
print(int("123"))        # 123
print(float("123.4"))    # 123.4
print(float("120"))      # 120.0
print(int("123S"))       # ValueError (has a non-numeric character)
print(int("123.4"))      # ValueError (a float-looking text can't go straight to int)
```
To convert `"123.4"` to an integer, go through `float` first:
```python
print(int(float("123.4")))   # 123
```

### Common checking methods (quick preview)
```python
print("hello".isalpha())     # True  (only letters)
print("123".isdigit())       # True  (only digits)
print("abc123".isalnum())    # True  (letters + digits)
print("   ".isspace())       # True  (only spaces)
```
