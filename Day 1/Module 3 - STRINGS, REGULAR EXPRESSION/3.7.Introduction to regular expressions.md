## 7. Introduction to Regular Expressions

### The problem
Imagine you have 10,000 customer messages and you need to:
- find every **phone number**
- check whether an **email address** is valid
- extract all **dates**
- remove all **numbers** from the text

With normal string methods like `find()` and `replace()`, this is very hard, because phone numbers and emails don't look **exactly** the same every time. You need to search by **pattern**.

### What is a regular expression?
A **regular expression** (**regex** or **regexp**) is a **pattern** that describes a *shape* of text. Python then finds all the text that fits that pattern.

Real-life example: when you say *"find me a 10-digit number starting with 9"*, you are describing a **pattern**, not an exact value. A regex lets you say the same thing to Python.

### Python's `re` module
Python has a built-in module for regex called **`re`**. You must import it.

```python
import re
```

### Your first regex
```python
import re

text = "My phone number is 9876543210"
result = re.search(r"\d+", text)

print(result.group())    # 9876543210
```
- `\d` means *a digit*.
- `+` means *one or more*.
- So `\d+` means *"one or more digits in a row"*.

### Always use raw strings for patterns
Write patterns as `r"..."`. This stops Python from treating the backslash as an escape.
```python
pattern = r"\d+"       # correct
pattern = "\d+"        # works with a warning, risky!
```

### Literal matching (the simplest pattern)
Normal letters match themselves.
```python
import re
print(re.search(r"cat", "I have a cat"))     # <re.Match object; span=(9, 12), match='cat'>
print(re.search(r"dog", "I have a cat"))     # None
```
If nothing is found, you get **`None`**.

### Special characters (metacharacters)
These have **special meaning** in a regex:
```
.  ^  $  *  +  ?  {  }  [  ]  \  |  (  )
```
To match them literally, put a backslash before them: `\.` matches an actual dot.

### The dot `.`: any single character
```python
print(re.findall(r"c.t", "cat cot cut c9t"))    # ['cat', 'cot', 'cut', 'c9t']
```

### Anchors: where in the text?
- `^` matches the **start** of the string
- `$` matches the **end** of the string

```python
print(re.search(r"^Hello", "Hello World"))     # match
print(re.search(r"^World", "Hello World"))     # None
print(re.search(r"World$", "Hello World"))     # match
```

### The OR operator `|`
```python
print(re.findall(r"cat|dog", "I have a cat and a dog"))   # ['cat', 'dog']
```

### Where is regex used?
- Validating emails, phone numbers, PIN codes
- Extracting data from logs and web pages
- Cleaning text for AI and NLP projects
- Search and replace with patterns
