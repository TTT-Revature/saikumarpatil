## 5. Escape Characters and Multiline Strings

### Escape characters
An **escape character** is a **backslash `\`** followed by a letter. It gives a **special meaning** to the next character.

Why do we need them? Some characters (like a new line, a tab or a quote) are hard to type inside a string.

**Common escape sequences:**
- `\n` → new line
- `\t` → tab (a wide gap)
- `\\` → a single backslash
- `\'` → a single quote
- `\"` → a double quote

```python
print("Hello\nWorld")
```
```
Hello
World
```
```python
print("Name\tAge")
print("Asha\t21")
```
```
Name    Age
Asha    21
```
```python
print("She said \"Hi\"")     # She said "Hi"
print('It\'s fine')          # It's fine
print("C:\\Users\\Sai")      # C:\Users\Sai
```

### Raw strings (when you don't want escapes to work)
Put an `r` before the quote. Python then treats backslashes as **plain text**. This is very useful for file paths and regular expressions.
```python
print("C:\new\table")      # \n and \t are treated as escapes → messy output
print(r"C:\new\table")     # C:\new\table  (printed exactly as typed)
```

### Multiline strings
Use **triple quotes** (`'''` or `"""`) to write a string over **multiple lines**. The line breaks are kept exactly as typed.

```python
address = """Sai Kumar
12, Gandhi Street
Chennai - 600001"""

print(address)
```
```
Sai Kumar
12, Gandhi Street
Chennai - 600001
```

**Alternative using `\n`:**
```python
print("Line 1\nLine 2\nLine 3")
```

**Splitting a multiline string into lines:**
```python
text = """apple
banana
mango"""
print(text.splitlines())     # ['apple', 'banana', 'mango']
```

### Writing a long string across lines in code
Use brackets, and Python joins the pieces automatically:
```python
message = (
    "Python is easy to learn. "
    "It is used in AI, web and automation."
)
print(message)
```

### Real-time example: an email template
```python
name = "Asha"
mail = f"""Dear {name},

Welcome to the Python course.
Your classes start on Monday.

Regards,
Trainer"""

print(mail)
```
