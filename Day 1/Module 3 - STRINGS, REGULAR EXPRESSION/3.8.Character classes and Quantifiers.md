## 8. Character Classes and Quantifiers

A regex is built from two ideas:
1. **Character classes:** *what kind of character* to match
2. **Quantifiers:** *how many times* to match it

### A. Character classes

**Shorthand classes:**
- `\d` → any **digit** (0-9)
- `\D` → anything that is **not** a digit
- `\w` → any **word character** (letters, digits, underscore)
- `\W` → anything that is **not** a word character
- `\s` → any **whitespace** (space, tab, new line)
- `\S` → anything that is **not** whitespace

```python
import re

text = "Order 123 costs 450 rupees"

print(re.findall(r"\d", text))     # ['1', '2', '3', '4', '5', '0']
print(re.findall(r"\d+", text))    # ['123', '450']
print(re.findall(r"\w+", text))    # ['Order', '123', 'costs', '450', 'rupees']
print(re.findall(r"\s", text))     # [' ', ' ', ' ', ' ']
```

**Custom classes using square brackets `[ ]`:**
- `[abc]` → matches **a, b or c**
- `[a-z]` → any **lowercase** letter
- `[A-Z]` → any **uppercase** letter
- `[0-9]` → any digit (same as `\d`)
- `[a-zA-Z]` → any letter
- `[^0-9]` → anything **except** digits (`^` inside brackets means NOT)

```python
print(re.findall(r"[aeiou]", "education"))      # ['e', 'u', 'a', 'i', 'o']
print(re.findall(r"[A-Z]", "Hello World"))      # ['H', 'W']
print(re.findall(r"[^0-9]", "a1b2c3"))          # ['a', 'b', 'c']
```

### B. Quantifiers (how many?)

- `*` → **zero or more** times
- `+` → **one or more** times
- `?` → **zero or one** time (optional)
- `{n}` → **exactly n** times
- `{n,}` → **n or more** times
- `{n,m}` → **between n and m** times

```python
import re

print(re.findall(r"\d{3}", "12 345 6789"))      # ['345', '678']
print(re.findall(r"\d{2,4}", "1 22 333 4444"))  # ['22', '333', '4444']
print(re.findall(r"colou?r", "color colour"))   # ['color', 'colour']
print(re.findall(r"go*d", "gd god good goood")) # ['gd', 'god', 'good', 'goood']
```

### Greedy vs lazy matching
By default, quantifiers are **greedy**: they grab **as much as possible**. Add `?` after them to make them **lazy** (as little as possible).

```python
text = "<b>Hello</b> and <b>World</b>"

print(re.findall(r"<b>.*</b>", text))      # ['<b>Hello</b> and <b>World</b>']   (greedy)
print(re.findall(r"<b>.*?</b>", text))     # ['<b>Hello</b>', '<b>World</b>']    (lazy)
```

### Putting it together: real patterns

**Indian mobile number (10 digits, starting with 6-9):**
```python
pattern = r"[6-9]\d{9}"
print(re.findall(pattern, "Call 9876543210 or 1234567890"))   # ['9876543210']
```

**PIN code (6 digits):**
```python
print(re.findall(r"\b\d{6}\b", "Chennai 600001, Delhi 110001"))   # ['600001', '110001']
```
`\b` marks a **word boundary**, so we don't pick 6 digits from a longer number.

**Simple email pattern:**
```python
pattern = r"\w+@\w+\.\w+"
print(re.findall(pattern, "Mail me at sai@gmail.com or asha@yahoo.com"))
# ['sai@gmail.com', 'asha@yahoo.com']
```

### Quick cheat sheet
- `\d` digit, `\w` word character, `\s` space
- `.` any character, `[abc]` one of a, b or c, `[^abc]` not a, b or c
- `*` 0 or more, `+` 1 or more, `?` 0 or 1, `{n}` exactly n
- `^` start, `$` end, `\b` word boundary, `|` OR
