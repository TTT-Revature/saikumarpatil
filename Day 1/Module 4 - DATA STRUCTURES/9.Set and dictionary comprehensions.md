## 9. Set and Dictionary Comprehensions

The same idea works for **sets** and **dictionaries**.

### A. Set comprehension
Use **curly brackets** `{ }` with a **single expression**. The result is a **set**, so duplicates vanish automatically.

```python
{ expression  for item in iterable  if condition }
```

```python
numbers = [1, 2, 2, 3, 3, 3, 4]
unique_squares = {n * n for n in numbers}
print(unique_squares)       # {1, 4, 9, 16}
```

**Unique first letters:**
```python
words = ["apple", "avocado", "banana", "blueberry", "cherry"]
print({w[0] for w in words})      # {'a', 'b', 'c'}   (order may vary)
```

**Unique word lengths:**
```python
print({len(w) for w in words})    # {5, 6, 7, 9}  (order may vary)
```

**Vowels in a sentence:**
```python
sentence = "python programming"
print({ch for ch in sentence if ch in "aeiou"})    # {'o', 'a', 'i'}   (order may vary)
```

### B. Dictionary comprehension
Use curly brackets with **`key: value`** pairs.

```python
{ key_expression : value_expression  for item in iterable  if condition }
```

**Squares table:**
```python
squares = {n: n * n for n in range(1, 6)}
print(squares)       # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

**Word and its length:**
```python
words = ["python", "is", "fun"]
print({w: len(w) for w in words})      # {'python': 6, 'is': 2, 'fun': 3}
```

**Two lists into one dictionary (with `zip`):**
```python
names = ["Asha", "Ravi", "Meena"]
marks = [85, 72, 90]

result = {n: m for n, m in zip(names, marks)}
print(result)        # {'Asha': 85, 'Ravi': 72, 'Meena': 90}
```

**Filtering a dictionary:**
```python
result = {"Asha": 85, "Ravi": 35, "Meena": 90}
passed = {name: m for name, m in result.items() if m >= 40}
print(passed)        # {'Asha': 85, 'Meena': 90}
```

**Changing the values:**
```python
prices = {"rice": 60, "milk": 25}
with_tax = {item: price * 1.05 for item, price in prices.items()}
print(with_tax)      # {'rice': 63.0, 'milk': 26.25}
```

**Swapping keys and values:**
```python
d = {"a": 1, "b": 2, "c": 3}
swapped = {v: k for k, v in d.items()}
print(swapped)       # {1: 'a', 2: 'b', 3: 'c'}
```

**Counting letters:**
```python
word = "banana"
count = {ch: word.count(ch) for ch in set(word)}
print(count)         # {'b': 1, 'a': 3, 'n': 2}   (order may vary)
```

### Which brackets mean what?
- `[ x for ... ]` → **list** comprehension
- `{ x for ... }` → **set** comprehension (one value)
- `{ k: v for ... }` → **dictionary** comprehension (a `key: value` pair)
- `( x for ... )` → **generator** (not a tuple!)

> There is no "tuple comprehension". Use `tuple(x for x in data)` if you need a tuple.

### Real-time example: build a lookup table from a list of records
```python
employees = [
    {"id": 101, "name": "Asha"},
    {"id": 102, "name": "Ravi"},
    {"id": 103, "name": "Meena"},
]

lookup = {e["id"]: e["name"] for e in employees}
print(lookup)            # {101: 'Asha', 102: 'Ravi', 103: 'Meena'}
print(lookup[102])       # Ravi
```

### Real-time example: grade each student
```python
marks = {"Asha": 85, "Ravi": 35, "Meena": 62}

grades = {
    name: ("Pass" if m >= 40 else "Fail")
    for name, m in marks.items()
}
print(grades)      # {'Asha': 'Pass', 'Ravi': 'Fail', 'Meena': 'Pass'}
```
