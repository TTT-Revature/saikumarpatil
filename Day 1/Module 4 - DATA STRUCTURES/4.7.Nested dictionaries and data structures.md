## 7. Nested Dictionaries and Data Structures

### What does "nested" mean?
Real data is rarely flat. A student has a name **and** a list of marks **and** an address (which itself has a street and a city). To store this, we put **containers inside other containers**.

Real-life example: a school register. The school has **classes**, each class has **students**, and each student has **details**.

### A dictionary inside a dictionary
```python
students = {
    "S101": {"name": "Asha", "age": 21, "city": "Chennai"},
    "S102": {"name": "Ravi", "age": 22, "city": "Mumbai"},
    "S103": {"name": "Meena", "age": 20, "city": "Delhi"},
}
```

**Accessing:** use **one key after another**, the same idea as `l[4][1]` in nested lists.
```python
print(students["S101"])              # {'name': 'Asha', 'age': 21, 'city': 'Chennai'}
print(students["S101"]["name"])      # Asha
print(students["S102"]["city"])      # Mumbai
```

**Changing and adding:**
```python
students["S101"]["age"] = 22                 # update
students["S101"]["phone"] = "9876543210"     # add a new detail
students["S104"] = {"name": "Kumar", "age": 23, "city": "Pune"}   # add a new student
```

**Deleting:**
```python
del students["S103"]                  # delete a whole student
del students["S101"]["phone"]         # delete one detail
```

**Looping through nested dictionaries:**
```python
for sid, info in students.items():
    print(f"ID: {sid}")
    for key, value in info.items():
        print(f"   {key}: {value}")
```
```
ID: S101
   name: Asha
   age: 22
   city: Chennai
...
```

**Safe access with `get()`:**
```python
print(students.get("S999", {}).get("name", "Not found"))     # Not found
```

### Lists inside dictionaries
```python
student = {
    "name": "Asha",
    "marks": [85, 90, 78],
    "address": {"street": "12 Gandhi St", "city": "Chennai"},
}

print(student["marks"][1])               # 90
print(student["address"]["city"])        # Chennai

student["marks"].append(92)
print(sum(student["marks"]) / len(student["marks"]))     # average
```

### Dictionaries inside lists (very common!)
This is how most **data from files and APIs** looks (like rows in a table).
```python
employees = [
    {"name": "Asha", "dept": "IT", "salary": 50000},
    {"name": "Ravi", "dept": "HR", "salary": 40000},
    {"name": "Meena", "dept": "IT", "salary": 55000},
]

print(employees[0]["name"])       # Asha

for emp in employees:
    print(emp["name"], "earns", emp["salary"])

it_team = [e["name"] for e in employees if e["dept"] == "IT"]
print(it_team)                    # ['Asha', 'Meena']
```

### A nested list (matrix / grid)
```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]

print(matrix[1][2])       # 6   (row 1, column 2)

for row in matrix:
    for value in row:
        print(value, end=" ")
    print()
```

### Choosing the right data structure

- Items that **change** and need **order** → **list**
- Data that must **never change** → **tuple**
- **Unique** items, or fast membership checks, or **set maths** → **set**
- **Labelled** data (look up by name or ID) → **dictionary**

### Real-time example: a small inventory system
```python
inventory = {
    "laptop": {"price": 55000, "stock": 5},
    "mouse": {"price": 500, "stock": 40},
    "keyboard": {"price": 1200, "stock": 15},
}

inventory["mouse"]["stock"] -= 3        # sold 3 mice

total_value = 0
for item, details in inventory.items():
    value = details["price"] * details["stock"]
    print(f"{item:<10} Rs.{value:>8,}")
    total_value += value

print("Total stock value: Rs.", f"{total_value:,}")
```

### A word on JSON
Nested dictionaries and lists look exactly like **JSON**, the format used by almost every web service and API. Learning to read nested data now makes your later work with APIs and AI tools much easier.

```python
import json

data = {"name": "Asha", "skills": ["Python", "SQL"]}
text = json.dumps(data)         # dict → JSON string
back = json.loads(text)         # JSON string → dict
```
