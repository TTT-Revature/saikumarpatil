## 2. List Methods and Sorting

### A very important difference from strings
A string method returns a **new** string and leaves the original alone. **A list method changes the original list itself.**

```python
l = [1, 2, 3]
l.append(4)
print(l)       # [1, 2, 3, 4]   (the original list was changed)
```
> Because list methods work **in place**, many of them return `None`. So don't write `l = l.append(4)`, because that would make `l` become `None`.

### Adding items

**`append(x)`** adds **one item** at the **end**.
```python
l = [1, 2, 3, 4]
l.append([5, 6])
print(l)       # [1, 2, 3, 4, [5, 6]]    ← the whole list was added as ONE item
```

**`extend(iterable)`** adds **each item separately** at the end.
```python
l = [1, 2, 3, 4]
l.extend([5, 6])
print(l)       # [1, 2, 3, 4, 5, 6]
```

**Quick memory trick:** `append` adds **one** thing (even if that thing is a list). `extend` adds **many** things one by one.

**`insert(index, item)`** adds an item at a **specific position**.
```python
l = [10, 20, 40]
l.insert(2, 30)
print(l)       # [10, 20, 30, 40]
```

### Removing items

**`remove(x)`** removes the **first matching value**. It raises a `ValueError` if the value isn't found.
```python
l = [10, 20, 30, 20]
l.remove(20)
print(l)       # [10, 30, 20]
```

**`pop(index)`** removes the item at that **index** and **returns** it. With no index, it removes the **last** item.
```python
l = [10, 20, 30, 40]
last = l.pop()
print(last)    # 40
print(l)       # [10, 20, 30]

second = l.pop(1)
print(second)  # 20
print(l)       # [10, 30]
```

**`del`** removes by index or slice.
```python
l = [10, 20, 30, 40, 50]
del l[0]
print(l)       # [20, 30, 40, 50]
del l[1:3]
print(l)       # [20, 50]
```

**`clear()`** empties the whole list.
```python
l = [1, 2, 3]
l.clear()
print(l)       # []
```

### Searching and counting
```python
l = [10, 20, 30, 20, 20]

print(l.count(20))      # 3     (how many times)
print(l.index(30))      # 2     (position of the first match)
```

### Sorting

**`sort()`** sorts the list **in place** (changes the original).
```python
l = [30, 10, 50, 20]
l.sort()
print(l)                # [10, 20, 30, 50]

l.sort(reverse=True)
print(l)                # [50, 30, 20, 10]
```

**`sorted()`** is a **function** that returns a **new sorted list** and leaves the original untouched.
```python
l = [30, 10, 50, 20]
new = sorted(l)
print(new)              # [10, 20, 30, 50]
print(l)                # [30, 10, 50, 20]   (original unchanged)
```

**Sorting strings:**
```python
names = ["Ravi", "asha", "Meena"]
print(sorted(names))                  # ['Meena', 'Ravi', 'asha']   (capital letters first)
print(sorted(names, key=str.lower))   # ['asha', 'Meena', 'Ravi']   (ignore case)
```

**Sorting by a custom rule with `key`:**
```python
words = ["banana", "kiwi", "apple", "fig"]
print(sorted(words, key=len))         # ['fig', 'kiwi', 'apple', 'banana']  (shortest word first)
```

> **Common mistake:** you can't sort a list that mixes numbers and text, such as `[3, "a", 1]`. It raises a `TypeError`.

### Reversing
```python
l = [1, 2, 3]
l.reverse()
print(l)        # [3, 2, 1]
```

### Useful built-in functions for lists
```python
l = [4, 8, 15, 16, 23, 42]
print(len(l))     # 6
print(sum(l))     # 108
print(max(l))     # 42
print(min(l))     # 4
```

### Method summary
- `append(x)` add one item at the end
- `extend(list)` add many items at the end
- `insert(i, x)` add at position `i`
- `remove(x)` remove by value
- `pop(i)` remove by index and return it
- `clear()` remove everything
- `count(x)` count occurrences
- `index(x)` find position
- `sort()` sort in place
- `reverse()` reverse in place
- `copy()` make a copy (next topic)

### Real-time example: a to-do list
```python
todo = []

todo.append("Wake up")
todo.append("Study Python")
todo.append("Exercise")
todo.insert(1, "Drink water")

print(todo)
todo.remove("Exercise")
print("After removing:", todo)

done = todo.pop(0)
print("Completed:", done)
print("Remaining:", todo)
```
