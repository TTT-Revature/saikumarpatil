## 4. Tuples

### What is a tuple?
A **tuple** is like a list, **except it is immutable**: once created, you **cannot change, add or remove** its elements.

- Written with **round brackets** `( )`
- **Ordered** (indexing and slicing work)
- **Immutable**
- Allows **duplicates**
- Can hold **mixed types**

Real-life example: coordinates `(13.08, 80.27)`, a date of birth `(15, 8, 1999)` or the days of the week. These are fixed facts that should not change by mistake.

### Creating tuples
```python
t1 = (1, 2, 3)
t2 = 1, 2, 3                   # brackets are optional
t3 = tuple([1, 2, 3])          # from a list
empty1 = ()                    # empty tuple
empty2 = tuple()               # empty tuple
```

### The one-item tuple trap
A tuple with **one item needs a trailing comma**. Without it, Python sees plain brackets.
```python
a = (5)
b = (5,)
print(type(a))     # <class 'int'>
print(type(b))     # <class 'tuple'>
```

### Indexing and slicing
```python
t = (10, 20, 30, 40, 50)

print(t[0])        # 10
print(t[-1])       # 50
print(t[1:4])      # (20, 30, 40)
print(len(t))      # 5
```

### Immutable: you can't change it
```python
t[0] = 99          # TypeError: 'tuple' object does not support item assignment
```
There is no `append`, `remove` or `sort` for tuples.

### Only two tuple methods
```python
t = (1, 2, 2, 3, 2)
print(t.count(2))      # 3
print(t.index(3))      # 3
```

### How to "modify" a tuple (the workaround)
Convert to a list, change it, and convert back:
```python
t = (1, 2, 3)
temp = list(t)
temp.append(4)
t = tuple(temp)
print(t)     # (1, 2, 3, 4)
```
Or build a new tuple: `t = t + (4,)`.

### Tuple unpacking (a favourite Python feature)
```python
point = (10, 20)
x, y = point
print(x, y)        # 10 20
```
```python
a, b = 1, 2
a, b = b, a        # swap using tuples!
```
Star unpacking:
```python
first, *middle, last = (1, 2, 3, 4, 5)
print(first, middle, last)    # 1 [2, 3, 4] 5
```

### A catch: a tuple can contain mutable items
```python
t = (1, [10, 20])
t[1].append(30)
print(t)     # (1, [10, 20, 30])
```
The tuple itself is not changed (it still points to the same list). The list **inside** was changed.

### Why use a tuple instead of a list?
- **Safety:** the data can't be changed by accident.
- **Speed and memory:** slightly faster and lighter than lists.
- **Dictionary keys:** tuples can be keys in a dictionary, but lists can't.
- A function can **return multiple values** as a tuple.

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([4, 9, 1, 7])
print(low, high)     # 1 9
```

### List vs tuple at a glance
- **List:** `[ ]`, mutable, many methods. Use it for data that changes (shopping cart).
- **Tuple:** `( )`, immutable, only `count` and `index`. Use it for fixed data (coordinates).
