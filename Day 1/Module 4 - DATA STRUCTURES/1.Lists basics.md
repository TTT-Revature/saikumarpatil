
### Big picture first
A variable like `a = 10` holds **one** value. Real programs need to hold **many** values together: a class list of 40 students, a shopping cart, a phone book. Python's **data structures** (also called *containers* or *advanced data types*) are built for exactly that.

Real-life comparison to give students:
- **List:** a shopping list. Ordered, you can add, remove and change items.
- **Tuple:** your date of birth. Ordered, but fixed forever.
- **Set:** a bag of unique lottery tickets. No order, no duplicates.
- **Dictionary:** a phone book. You look up a **name (key)** to get a **number (value)**.

## 1. Lists: Creation, Access, Indexing and Slicing

### What is a list?
A **list** stores **multiple items in one variable**, in a specific order.

- Written with **square brackets** `[ ]`
- Items are separated by commas
- It is **mutable**: you can change it after creation
- It can hold **any data types**, even mixed ones
- It allows **duplicates**

```python
numbers = [1, 2, 3, 4]
fruits = ["apple", "banana", "mango"]
mixed = [10, "Asha", 5.5, True]
```

### Creating lists
```python
a = [10, 20, 30]            # using square brackets
b = list("python")          # from a string → ['p', 'y', 't', 'h', 'o', 'n']
c = list(range(1, 6))       # from range  → [1, 2, 3, 4, 5]
d = []                      # empty list
e = list()                  # another empty list
```

### Length of a list: `len()`
For a list, `len()` counts the **number of items** (in a string it counts characters).
```python
print(len([10, 20, 30]))      # 3
```

### Indexing (access ONE item)
It works **exactly like string indexing**: positive indexes start from **0**, and negative indexes start from **-1**.

```python
l = [10, 20, 30, 40, 50]

print(l[0])      # 10
print(l[2])      # 30
print(l[-1])     # 50  (last item)
print(l[-2])     # 40
print(l[10])     # IndexError: list index out of range
```

### Changing an item (lists are mutable)
```python
l[1] = 99
print(l)         # [10, 99, 30, 40, 50]
```
> Compare this with strings, where `s[0] = "x"` is an error. This is the main difference between mutable and immutable.

### Nested list indexing
A list can contain **another list**. Use **two index brackets**: the first picks the inner list, and the second picks the item inside it.

```python
l = [10, 20, 30, 40, [1, 2, 3]]

print(l[4])        # [1, 2, 3]
print(l[4][1])     # 2
```
Python runs the first index, takes that result, and then applies the next index to it.

### Slicing (access MANY items)
**Syntax:** `list[start : end : step]`, where `start` is included and `end` is **excluded**.

```python
l = [10, 20, 30, 40, 50, 60]

print(l[1:4])      # [20, 30, 40]
print(l[:3])       # [10, 20, 30]
print(l[3:])       # [40, 50, 60]
print(l[::2])      # [10, 30, 50]
print(l[::-1])     # [60, 50, 40, 30, 20, 10]   (reversed)
print(l[-3:])      # [40, 50, 60]
print(l[2:100])    # [30, 40, 50, 60]   (no error in slicing)
```
- Indexing → **error** if out of range
- Slicing → **no error**; it gives whatever is available

### Joining and repeating lists
```python
l1 = [1, 2, 3]
l2 = [4, 5]

print(l1 + l2)      # [1, 2, 3, 4, 5]
print(l1 * 2)       # [1, 2, 3, 1, 2, 3]
```

### Checking and looping
```python
print(20 in [10, 20, 30])        # True
print(99 not in [10, 20, 30])    # True

for fruit in ["apple", "banana", "mango"]:
    print(fruit)
```

### Real-time example: class marks
```python
marks = [78, 92, 65, 88, 70]

print("First student :", marks[0])
print("Last student  :", marks[-1])
print("Top 3 students:", sorted(marks, reverse=True)[:3])
print("Total        :", sum(marks))
print("Highest      :", max(marks))
print("Lowest       :", min(marks))
print("Average      :", sum(marks) / len(marks))
```
