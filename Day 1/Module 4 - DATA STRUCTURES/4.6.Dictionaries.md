## 6. Dictionaries: Keys, Values and Common Operations

### What is a dictionary?
A **dictionary** (`dict`) stores data as **key : value pairs**.

- Written with **curly brackets** `{ }`, with `key: value` inside
- You look things up by **key** (not by position)
- **Keys must be unique** and **immutable** (strings, numbers, tuples)
- **Values** can be anything, and can be repeated
- **Mutable**: you can add, change and delete pairs
- Keeps **insertion order** (Python 3.7+)

Real-life example: a **phone book**. You don't look up "the 5th entry". You look up a **name (key)** and get a **number (value)**. A **dictionary** works the same way: the word is the key and the meaning is the value.

### Creating dictionaries
```python
student = {"name": "Asha", "age": 21, "city": "Chennai"}

empty1 = {}
empty2 = dict()

d = dict(name="Ravi", age=22)                   # using dict()
pairs = dict([("a", 1), ("b", 2)])              # from a list of pairs
```

### Accessing values

**Using the key in square brackets:**
```python
print(student["name"])       # Asha
print(student["phone"])      # KeyError: 'phone'
```

**Using `get()`: the safe way** (no error if the key is missing)
```python
print(student.get("phone"))                # None
print(student.get("phone", "Not given"))   # Not given   (custom default)
print(student.get("name"))                 # Asha
```

### Adding and changing
The **same syntax** does both. If the key exists, the value is **updated**. If it doesn't, a **new pair is added**.
```python
student["age"] = 22              # update
student["phone"] = "9876543210"  # add new
print(student)
```

**`update()`** adds or changes **many pairs at once**:
```python
marks = {"history": 45, "Hindi": 56}
marks.update({"chemistry": 89, "maths": 100})
print(marks)
# {'history': 45, 'Hindi': 56, 'chemistry': 89, 'maths': 100}
```

### Deleting items

**Option 1: `del`**
```python
marks = {"history": 45, "Hindi": 56}
del marks["history"]
print(marks)       # {'Hindi': 56}
```

**Option 2: `pop(key)`** removes the pair and **returns the value**
```python
marks = {"history": 45, "Hindi": 56}
value = marks.pop("history")
print(value)       # 45
print(marks)       # {'Hindi': 56}
```
`pop` raises a `KeyError` for a missing key, unless you give a default: `marks.pop("xyz", None)`.

**Option 3: `popitem()`** removes the **last added** pair.
```python
marks.popitem()
```

**Option 4: `clear()`** removes **everything**.
```python
marks.clear()
print(marks)       # {}
```

### Keys, values and items
```python
student = {"name": "Asha", "age": 21, "city": "Chennai"}

print(student.keys())      # dict_keys(['name', 'age', 'city'])
print(student.values())    # dict_values(['Asha', 21, 'Chennai'])
print(student.items())     # dict_items([('name', 'Asha'), ('age', 21), ('city', 'Chennai')])
```

### Looping through a dictionary
```python
for key in student:                       # keys (default)
    print(key)

for value in student.values():            # values
    print(value)

for key, value in student.items():        # both
    print(key, "→", value)
```
```
name → Asha
age → 21
city → Chennai
```

### Checking if a key exists
`in` checks the **keys**, not the values.
```python
print("name" in student)       # True
print("Asha" in student)       # False   (that's a value)
print("Asha" in student.values())   # True
```

### Other handy operations
```python
print(len(student))                # 3
copy1 = student.copy()             # shallow copy
student.setdefault("country", "India")   # add only if the key is missing
```

### Merging dictionaries
```python
a = {"x": 1, "y": 2}
b = {"y": 99, "z": 3}

print(a | b)               # {'x': 1, 'y': 99, 'z': 3}   (b wins for duplicate keys)
```

### Real-time example: word frequency counter
```python
text = "to be or not to be"
count = {}

for word in text.split():
    count[word] = count.get(word, 0) + 1

print(count)      # {'to': 2, 'be': 2, 'or': 1, 'not': 1}
```

### Real-time example: a simple shopping bill
```python
prices = {"rice": 60, "milk": 25, "sugar": 45}
cart = {"rice": 2, "milk": 3}

total = 0
for item, qty in cart.items():
    total += prices[item] * qty

print("Total bill: Rs.", total)      # 195
```

### Dictionary vs list
- **List:** you find items by **position** (`l[0]`).
- **Dictionary:** you find items by **meaningful keys** (`d["name"]`). It is much better for labelled data.
