## 5. Sets and Set Operations

### What is a set?
A **set** is a collection of **unique items** with **no fixed order**.

- Written with **curly brackets** `{ }`
- **No duplicates** (duplicates are removed automatically)
- **Unordered**, so there is **no indexing and no slicing**
- **Mutable**: you can add and remove items
- Items inside must be **immutable** (numbers, strings, tuples). A list can't go inside a set.

Real-life example: a **list of unique email addresses** for a newsletter, or the **set of students who attended** a class. Each name appears only once.

### Creating sets
```python
s = {1, 2, 3, 3, 2}
print(s)                       # {1, 2, 3}   (duplicates removed)

s2 = set([1, 2, 2, 3])         # from a list
s3 = set("hello")              # {'h', 'e', 'l', 'o'}  (order may vary)
empty = set()                  # empty set
```

> **Trap:** `{}` creates an **empty dictionary**, not an empty set. For an empty set, always use `set()`.

### The most useful trick: remove duplicates from a list
```python
names = ["Asha", "Ravi", "Asha", "Meena", "Ravi"]
unique = list(set(names))
print(unique)      # e.g. ['Meena', 'Asha', 'Ravi']   (order not guaranteed)
```

### No indexing
```python
s = {10, 20, 30}
print(s[0])        # TypeError: 'set' object is not subscriptable
```

### Adding and removing
```python
s = {1, 2, 3}

s.add(4)            # {1, 2, 3, 4}
s.update([5, 6])    # {1, 2, 3, 4, 5, 6}   (add many)

s.remove(6)         # removes 6; raises KeyError if not found
s.discard(100)      # removes if present; NO error if missing
x = s.pop()         # removes and returns a random item
s.clear()           # empties the set
```

### Membership check (very fast)
```python
s = {10, 20, 30}
print(20 in s)       # True
```
Sets check membership **much faster** than lists, which matters for big data.

### Set operations (like Venn diagrams in maths)

Take two sets:
```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
```

**Union** (everything from both, without duplicates)
```python
print(A | B)              # {1, 2, 3, 4, 5, 6}
print(A.union(B))
```

**Intersection** (only what is **common** to both)
```python
print(A & B)              # {3, 4}
print(A.intersection(B))
```

**Difference** (in A but **not** in B)
```python
print(A - B)              # {1, 2}
print(A.difference(B))
print(B - A)              # {5, 6}
```

**Symmetric difference** (in either set but **not in both**)
```python
print(A ^ B)                          # {1, 2, 5, 6}
print(A.symmetric_difference(B))
```

### Checking relationships

**`issubset()`** is True if **all elements of the first set are in the second**.
```python
A = {3, 4, 5}
B = {3, 4, 5, 6}

print(A.issubset(B))        # True   (A is a subset of B)
print(B.issubset(A))        # False
print(B.issuperset(A))      # True   (B is a superset of A)
```
`A` is the **subset** (the smaller set inside), and `B` is the **superset** (the bigger set containing it).

**`isdisjoint()`** is True if the two sets have **nothing in common**.
```python
print({1, 2}.isdisjoint({3, 4}))     # True
print({1, 2}.isdisjoint({2, 3}))     # False
```

### Real-time example: two classes
```python
python_class = {"Asha", "Ravi", "Meena", "Kumar"}
sql_class = {"Ravi", "Divya", "Kumar", "Sai"}

print("Attending both    :", python_class & sql_class)
print("Attending any     :", python_class | sql_class)
print("Only Python       :", python_class - sql_class)
print("Only one of them  :", python_class ^ sql_class)
```

### Real-time example: finding duplicates
```python
emails = ["a@x.com", "b@x.com", "a@x.com"]

if len(emails) != len(set(emails)):
    print("Duplicates found!")
```

fs = frozenset([1, 2, 3])
