## 12. f-strings and Formatted Output

### What is an f-string?
An **f-string** (formatted string literal) lets you put **variables directly inside a string**. Just put an `f` before the opening quote and write variables inside **curly braces `{}`**.

It is the most modern, readable and recommended way to format output in Python (Python 3.6 and above).

### The old way vs the f-string way
```python
name = "Asha"
age = 21

# Old way (messy)
print("My name is " + name + " and I am " + str(age) + " years old")

# f-string way (clean)
print(f"My name is {name} and I am {age} years old")
```
With f-strings you don't need `str()` to convert numbers, and you don't need `+` to join pieces.

### You can run expressions inside `{}`
```python
price = 250
quantity = 3
print(f"Total = {price * quantity}")          # Total = 750
print(f"Is adult? {age >= 18}")               # Is adult? True
print(f"Name in capitals: {name.upper()}")    # Name in capitals: ASHA
```

### Formatting numbers

**Decimal places:** `:.2f` means 2 digits after the decimal point.
```python
pi = 3.14159265
print(f"Pi = {pi:.2f}")      # Pi = 3.14
```

**Thousands separator:**
```python
salary = 1500000
print(f"Salary: {salary:,}")      # Salary: 1,500,000
```

**Percentage:**
```python
score = 0.856
print(f"Score: {score:.1%}")      # Score: 85.6%
```

**Leading zeros:**
```python
print(f"Roll no: {7:03}")         # Roll no: 007
```

### Alignment and width
```python
print(f"{'Name':<10}{'Marks':>5}")
print(f"{'Asha':<10}{85:>5}")
print(f"{'Ravi':<10}{92:>5}")
```
```
Name      Marks
Asha         85
Ravi         92
```
- `<` aligns left
- `>` aligns right
- `^` centres
- the number is the total width

### Real-time example: a mini bill
```python
item = "Notebook"
price = 45.5
qty = 4
total = price * qty

print("=" * 30)
print(f"Item     : {item}")
print(f"Price    : Rs.{price:.2f}")
print(f"Quantity : {qty}")
print(f"Total    : Rs.{total:,.2f}")
print("=" * 30)
```

### Other ways to format (you may see these in older code)
```python
name = "Asha"
age = 21

print("My name is {} and I am {}".format(name, age))   # .format() method
print("My name is %s and I am %d" % (name, age))       # % formatting (oldest)
```

> **Recommendation:** Use **f-strings** for all new code.

### Debugging trick (Python 3.8+)
```python
x = 10
print(f"{x = }")      # x = 10
```
