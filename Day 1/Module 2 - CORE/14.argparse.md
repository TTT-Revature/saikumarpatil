## 14. `argparse` 

### What is `argparse`?
`argparse` is Python's **built-in module for building proper command-line tools**. It does the hard work that `sys.argv` leaves to you:

- reads and **names** the arguments
- **converts** them to the right data type
- creates an automatic **`--help`** message
- shows **friendly errors** when something is missing or wrong

Real-life example: `sys.argv` is like handing the waiter a messy handwritten note. `argparse` is like a **proper order form** with labelled boxes: name, quantity, special instructions. The form tells you if something is missing.

### Step-by-step basics

**Step 1:** import the module and create a parser.
**Step 2:** tell it which arguments you expect.
**Step 3:** read the values.

```python
# file name: greet.py
import argparse

parser = argparse.ArgumentParser(description="A simple greeting program")

parser.add_argument("name", help="Your name")
parser.add_argument("age", type=int, help="Your age")

args = parser.parse_args()

print(f"Hello {args.name}, next year you will be {args.age + 1}")
```
Run it:
```bash
python greet.py Asha 21
```
```
Hello Asha, next year you will be 22
```

Ask for help:
```bash
python greet.py --help
```
```
usage: greet.py [-h] name age

A simple greeting program

positional arguments:
  name        Your name
  age         Your age

options:
  -h, --help  show this help message and exit
```

If the user forgets an argument, `argparse` explains it automatically:
```
error: the following arguments are required: age
```

### Two kinds of arguments

**1. Positional arguments** are **required**, and the order matters.
```python
parser.add_argument("name")
```
```bash
python greet.py Asha
```

**2. Optional arguments** start with `--` (or `-`). They are not required and can be given in **any order**.
```python
parser.add_argument("--city", help="Your city")
parser.add_argument("--age", type=int, default=18, help="Your age")
```
```bash
python greet.py Asha --city Chennai --age 25
```
If the user doesn't provide an optional argument, it becomes `None`, or the `default` value if you set one.

### Useful options of `add_argument()`

- `type=int` converts the value to an integer
- `default=18` is used when the user gives nothing
- `help="..."` is the text shown in `--help`
- `required=True` makes an optional argument compulsory
- `choices=["a", "b"]` allows only the listed values
- `action="store_true"` makes an on/off **flag**
- `-n` as a second name gives a short form: `add_argument("-n", "--name")`

### Flags (on/off switches)
```python
parser.add_argument("--verbose", action="store_true", help="Show more details")
```
```bash
python app.py --verbose
```
`args.verbose` is `True` if the flag is given, and `False` if not.

### Restricting choices
```python
parser.add_argument("--level", choices=["easy", "medium", "hard"], default="easy")
```
If the user types `--level expert`, `argparse` rejects it with a clear error.

### Real-time example: a mini calculator tool
```python
# file name: calc.py
import argparse

parser = argparse.ArgumentParser(description="Simple calculator")

parser.add_argument("num1", type=float, help="First number")
parser.add_argument("num2", type=float, help="Second number")
parser.add_argument(
    "--op",
    choices=["add", "sub", "mul", "div"],
    default="add",
    help="Operation to perform (default: add)",
)

args = parser.parse_args()

if args.op == "add":
    result = args.num1 + args.num2
elif args.op == "sub":
    result = args.num1 - args.num2
elif args.op == "mul":
    result = args.num1 * args.num2
else:
    result = args.num1 / args.num2

print(f"Result: {result}")
```
```bash
python calc.py 10 5
python calc.py 10 5 --op mul
python calc.py 10 5 --op div
```
```
Result: 15.0
Result: 50.0
Result: 2.0
```

### `sys.argv` vs `argparse`
- Use **`sys.argv`** for tiny, quick scripts with one or two values.
- Use **`argparse`** for anything you want others to use: it gives you help text, type checks and clear errors.
- Most real-world Python command-line tools (including many AI/ML training scripts) use `argparse`.

### Using argparse in Jupyter Notebook
`argparse` expects real command-line input, so in Jupyter you can pass a list for testing:
```python
args = parser.parse_args(["Asha", "21"])
```
