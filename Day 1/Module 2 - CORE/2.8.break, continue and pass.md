## 8. `break`, `continue` and `pass`

These three statements **control the flow inside loops**.

### `break`: stop the loop completely
Real-life example: you are searching for your keys in the house. The moment you find them, you **stop searching**.

```python
for i in range(1, 10):
    if i == 5:
        break
    print(i)
```
```
1
2
3
4
```
When `i` becomes 5, the loop ends right there.

### `continue`: skip this round, go to the next
Real-life example: while checking exam papers, you find a blank paper. You **skip it and move to the next** one. You don't stop checking altogether.

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```
```
1
2
4
5
```
Number 3 was skipped, but the loop carried on.

### `pass`: do nothing (a placeholder)
Python **doesn't allow an empty block**. If you need a block but haven't written the code yet, use `pass`. It is like a "to be filled later" sticky note.

```python
for i in range(5):
    pass            # no error, does nothing

age = 20
if age > 18:
    pass            # will write this later
```

Without `pass`, an empty block gives an `IndentationError`.

### Quick comparison
- `break` → **exits** the loop
- `continue` → **skips** the current round only
- `pass` → **does nothing** and moves on

### Real-time example: find the first even number
```python
numbers = [7, 9, 11, 14, 17, 20]

for n in numbers:
    if n % 2 == 0:
        print("First even number is", n)
        break
```
**Output:** `First even number is 14`

### Real-time example: skip negative numbers
```python
marks = [80, -5, 90, -1, 70]

for m in marks:
    if m < 0:
        continue
    print("Valid mark:", m)
```
