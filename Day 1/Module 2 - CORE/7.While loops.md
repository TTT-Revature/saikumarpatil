## 7. `while` Loops

### What is a `while` loop?
A `while` loop **keeps repeating as long as a condition stays True**.

Real-life example: *"Keep stirring the tea until it boils."* You don't know exactly how many stirs it will take. You just keep going until the condition changes.

### `for` vs `while`
- Use **`for`** when you know **how many times** to repeat, or you are going through a collection.
- Use **`while`** when you **don't know** how many times, and you repeat *until something happens*.

### Syntax
```python
while condition:
    # code to repeat
```

```python
count = 1

while count <= 5:
    print("Count is", count)
    count += 1
```
```
Count is 1
Count is 2
Count is 3
Count is 4
Count is 5
```

### Three things every `while` loop needs
1. A **starting value** (`count = 1`)
2. A **condition** (`count <= 5`)
3. A **change** inside the loop (`count += 1`)

###  Infinite loop warning
If you forget the change, the condition **never becomes False** and the loop runs forever.
```python
count = 1
while count <= 5:
    print(count)
    # count never changes → infinite loop!
```
If this happens, press **Ctrl + C** in the terminal (or the stop button in Jupyter).

### Real-time example: password retry
```python
password = ""

while password != "python123":
    password = input("Enter password: ")

print("Access granted")
```

### Real-time example: guessing game
```python
secret = 7
guess = 0

while guess != secret:
    guess = int(input("Guess the number: "))
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")

print("Correct! You got it")
```

### Real-time example: digit sum
```python
number = 1234
total = 0

while number > 0:
    total += number % 10    # take the last digit
    number //= 10           # remove the last digit

print(total)   # 10
```
