## 10. Loop `else`

### A surprising Python feature
In Python, **loops can have an `else` block too**. The `else` block runs **when the loop finishes normally**, meaning it was **not stopped by `break`**.

Think of it as: *"If the search was never interrupted, then do this."*

### `for-else`
```python
for i in range(1, 4):
    print(i)
else:
    print("Loop finished without break")
```
```
1
2
3
Loop finished without break
```

### What does `break` do to `else`?

**Case 1: `break` is used → `else` does NOT run**
```python
for i in range(1, 6):
    if i == 3:
        print("Found 3, stopping")
        break
else:
    print("This will not print")
```
```
Found 3, stopping
```

**Case 2: `break` is not used (or never triggered) → `else` runs**
```python
for i in range(1, 6):
    if i == 10:
        break
else:
    print("10 was not found")
```
```
10 was not found
```

### `continue` does not affect `else`
`continue` has **nothing to do with `else`**. Even if `continue` is used, the `else` block still runs. Only `break` stops it.

```python
for i in range(1, 4):
    if i == 2:
        continue
    print(i)
else:
    print("else runs even with continue")
```
```
1
3
else runs even with continue
```

### `while-else`
Works the same way:
```python
count = 1
while count <= 3:
    print(count)
    count += 1
else:
    print("while loop completed")
```

### Don't confuse `if-else` with `for-else`
- **`if-else`:** if the condition is **False**, `else` runs. If the condition is **True**, `else` does not run.
- **`for-else`:** if `break` **is used**, `else` does **not** run. If `break` is **not used**, `else` **does** run.

### Real-time example: prime number check
```python
number = 17

for i in range(2, number):
    if number % i == 0:
        print(number, "is not a prime number")
        break
else:
    print(number, "is a prime number")
```
**Output:** `17 is a prime number`

If any divisor is found, `break` runs and the `else` message is skipped. If no divisor is found, the loop finishes normally, so `else` confirms it is prime.
