## 2. Logical, Membership and Identity Operators

### A. Logical operators

Logical operators combine **conditions**. They work with `True` and `False`.

- `and` gives True only if **both** conditions are True
- `or` gives True if **at least one** condition is True
- `not` **reverses** the result (True becomes False, False becomes True)

**Real-life example (loan approval):** a bank gives a loan if the person is above 21 **and** earns more than 25,000.

```python
age = 25
salary = 30000

print(age > 21 and salary > 25000)   # True  (both are true)
print(age > 30 and salary > 25000)   # False (first one fails)
print(age > 30 or salary > 25000)    # True  (second one is true)
print(not (age > 30))                # True  (reverses False)
```

**The "truth table" idea:**
```
True  and True   → True
True  and False  → False
False and True   → False
False and False  → False

True  or True    → True
True  or False   → True
False or True    → True
False or False   → False
```

> **Easy way to remember:**
> - `and` is strict: *everyone must agree*.
> - `or` is relaxed: *one yes is enough*.

### B. Membership operators

Membership operators check **whether a value is present inside a sequence** (string, list, tuple, set or dictionary).

- `in` is True if the value **is found**
- `not in` is True if the value **is not found**

```python
name = "Sai Kumar"
print("Sai" in name)        # True
print("xyz" in name)        # False
print("xyz" not in name)    # True
```
```python
fruits = ["apple", "banana", "mango"]
print("apple" in fruits)    # True
print("grapes" in fruits)   # False
```

For a **dictionary**, `in` checks the **keys**, not the values:
```python
student = {"name": "Asha", "age": 21}
print("name" in student)    # True  (key exists)
print("Asha" in student)    # False (that's a value, not a key)
```

### C. Identity operators

Identity operators check whether **two variables point to the very same object in memory**, not just whether they have the same value.

- `is` is True if both operands are the **identical** object
- `is not` is True if they are **not identical**

```python
a = 5
b = 5
print(a is b)       # True

a = 6
b = 8
print(a is not b)   # True
```

### `==` vs `is` (very common interview question)

Real-life example: two students have **identical copies** of the same textbook.
- `==` asks: *"Do both books have the same content?"* → Yes.
- `is` asks: *"Is this literally the same physical book?"* → No.

```python
list1 = [1, 2, 3]
list2 = [1, 2, 3]

print(list1 == list2)   # True  (same content)
print(list1 is list2)   # False (two different list objects)

list3 = list1
print(list1 is list3)   # True  (same object, just two names)
```

> **Tip:** You can confirm with `id()`. If `id(a) == id(b)`, then `a is b` is True.

> **Best practice:** Use `is` mainly for checking `None`, like `if x is None:`. For comparing values, use `==`.
