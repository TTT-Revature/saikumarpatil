## 11. `input()` and `print()`

### `print()`: showing output

```python
print("Hello")
print(12)
print("Total:", 250)
```

**Useful options:**

`sep` is what goes **between** values (default is a space):
```python
print("2025", "01", "15", sep="-")    # 2025-01-15
```

`end` is what goes at the **end** (default is a new line):
```python
print("Loading", end="...")
print("Done")
```
```
Loading...Done
```

Printing multiple lines in one `print`:
```python
print("Line 1\nLine 2")
```

### `input()`: taking data from the user

`input()` **pauses the program, waits for the user to type something and press Enter**, then gives you what they typed.

```python
name = input("Enter your name: ")
print("Hello,", name)
```

### The golden rule: `input()` always returns a **string**
```python
age = input("Enter your age: ")    # user types 24
print(age)           # 24
print(type(age))     # <class 'str'>  ← text, not a number
```

To do maths, **convert** it:
```python
age = int(input("Enter your age: "))
price = float(input("Enter price: "))
```

### Real-time example: simple calculator
```python
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

print("Sum        :", num1 + num2)
print("Difference :", num1 - num2)
print("Product    :", num1 * num2)
print("Quotient   :", num1 / num2)
```

### Taking multiple values in one line
```python
a, b = input("Enter two numbers: ").split()
a = int(a)
b = int(b)
print(a + b)
```
If the user types `10 20`, `.split()` breaks the text into `"10"` and `"20"`, which are then converted to integers.

A shorter version:
```python
a, b = map(int, input("Enter two numbers: ").split())
```

### Handling wrong input safely
```python
try:
    age = int(input("Enter your age: "))
    print("Next year you will be", age + 1)
except ValueError:
    print("Please enter a valid number")
```
