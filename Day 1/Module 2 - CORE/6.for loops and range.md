## 6. `for` Loops and `range()`

### Why loops?
Imagine writing `print("Hello")` 100 times. A **loop** repeats a block of code for you, which saves time and effort.

Real-life example: a teacher taking attendance calls out each student's name **one by one**. That is exactly what a `for` loop does: it picks items one by one.

### Syntax
```python
for variable in sequence:
    # code to repeat (indented)
```

A `for` loop can go through any **sequence**: a string, list, tuple, set, dictionary or a `range`.

### Looping over a list
```python
fruits = ["apple", "banana", "mango"]

for fruit in fruits:
    print(fruit)
```
```
apple
banana
mango
```

### Looping over a string
```python
for letter in "SIVA":
    print(letter)
```
```
S
I
V
A
```

### Looping over a dictionary
By default, a loop over a dictionary gives you the **keys**.
```python
d = {1: 25, "a": 45}

for i in d:
    print(i)
```
```
1
a
```

To get values or both:
```python
for value in d.values():
    print(value)          # 25, 45

for key, value in d.items():
    print(key, value)     # 1 25  and  a 45
```

### The `range()` function

`range()` generates a sequence of **numbers** for the loop.

```python
range(start, end, step)
```
- **start:** where to begin (default `0`)
- **end:** where to stop. **The end number is NOT included.**
- **step:** the gap between numbers (default `1`)

```python
for i in range(5):
    print(i)           # 0 1 2 3 4
```
```python
for i in range(1, 6):
    print(i)           # 1 2 3 4 5
```
```python
for i in range(2, 11, 2):
    print(i)           # 2 4 6 8 10
```
**Counting backwards** needs a negative step:
```python
for i in range(5, 0, -1):
    print(i)           # 5 4 3 2 1
```

> **Watch out:** If the step is not possible (for example `range(1, 5, -1)`), the output is **empty**. Nothing is printed and there is no error.

### Real-time example: multiplication table
```python
n = 5
for i in range(1, 11):
    print(n, "x", i, "=", n * i)
```

### Real-time example: sum of numbers
```python
total = 0
for i in range(1, 101):
    total += i
print("Sum of 1 to 100 =", total)    # 5050
```

### `enumerate()`: when you need the position too
```python
names = ["Asha", "Ravi", "Meena"]
for index, name in enumerate(names):
    print(index, name)
```
```
0 Asha
1 Ravi
2 Meena
```
