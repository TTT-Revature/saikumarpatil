## 5. Nested Conditions and Conditional Expressions

### A. Nested `if`
A **nested if** means an `if` statement **inside another `if`**. The inner condition is checked only if the outer condition is True.

Real-life example: *to enter an exam hall, you must first have a hall ticket. Only then will they check your ID card.*

```python
has_hall_ticket = True
has_id_card = True

if has_hall_ticket:
    if has_id_card:
        print("Welcome, you may enter")
    else:
        print("Please bring your ID card")
else:
    print("Hall ticket is required")
```

**Another example: a login check**
```python
username = "admin"
password = "1234"

if username == "admin":
    if password == "1234":
        print("Login successful")
    else:
        print("Wrong password")
else:
    print("User not found")
```

> **Tip:** Don't go too deep. Often a nested `if` can be written more simply using `and`:
> ```python
> if has_hall_ticket and has_id_card:
>     print("Welcome, you may enter")
> ```

### B. Conditional expression (ternary operator)

This is a **one-line `if-else`**. It is handy for simple decisions.

**Syntax:**
```python
value_if_true if condition else value_if_false
```

```python
age = 20
status = "Adult" if age >= 18 else "Minor"
print(status)    # Adult
```

Compare with the long way:
```python
if age >= 18:
    status = "Adult"
else:
    status = "Minor"
```

```python
a, b = 10, 25
biggest = a if a > b else b
print(biggest)   # 25
```

> **When to use it:** only for **short, simple** decisions. If it gets complicated, use a normal `if-else` so the code stays readable.
