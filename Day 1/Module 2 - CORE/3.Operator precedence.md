## 3. Operator Precedence

When an expression has **many operators**, which one does Python do first? That order is called **operator precedence**.

Real-life example: the school maths rule **BODMAS**. In `2 + 3 * 4`, multiplication goes first, so the answer is `14`, not `20`.

### Precedence order (highest to lowest)

1. `()` parentheses
2. `**` power
3. `+x`, `-x` (unary plus and minus)
4. `*`, `/`, `//`, `%`
5. `+`, `-`
6. Comparison, identity and membership operators: `==`, `!=`, `>`, `<`, `>=`, `<=`, `is`, `is not`, `in`, `not in`
7. `not`
8. `and`
9. `or`

```python
print(2 + 3 * 4)        # 14 (multiplication first)
print((2 + 3) * 4)      # 20 (brackets first)
print(2 ** 3 ** 2)      # 512 (power goes right to left: 3**2 = 9, then 2**9)
print(10 - 4 - 3)       # 3  (same level goes left to right)
```

**A logical example:**
```python
print(True or False and False)    # True
```
`and` is done first: `False and False` → `False`. Then `True or False` → `True`.

With brackets, the answer changes:
```python
print((True or False) and False)  # False
```

### Key rules
- Operators at the **same level** run from **left to right** (except `**`, which runs right to left).
- **When in doubt, use brackets.** They make code easier to read and remove any confusion.
