## 4. `if`, `elif` and `else` 

### Why do we need decisions?
Programs need to **make decisions**, just like we do in daily life: *"If it rains, I will take an umbrella. Otherwise, I will go without."*

Conditional statements are also called **control flow statements**. They control which part of the code runs.

The types are:
- `if`
- `if-else`
- `if-elif`
- `if-elif-else`
- nested `if`

### Block structure
A **block** is a group of lines that run together. In Python:
- The line before a block **ends with a colon `:`**
- The block is **indented** (4 spaces)
- The block runs **only when the condition is `True`**

### A. Simple `if`
```python
age = 20

if age >= 18:
    print("You are eligible to vote")
print("Program finished")
```
If the condition is False, the indented line is simply skipped.

### B. `if-else`
- If the condition is **True**, the `if` block runs.
- If the condition is **False**, the `else` block runs **automatically**.

```python
number = 7

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

### C. `if-elif-else`
Use this when you have **more than two choices**.

How it works:
- Python checks the `if` condition first.
- If it fails, Python moves to the first `elif`, then the next `elif`, and so on.
- If **every condition fails**, the `else` block runs.

```python
marks = 82

if marks >= 90:
    print("Grade A+")
elif marks >= 75:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
elif marks >= 40:
    print("Grade C")
else:
    print("Fail")
```
**Output:** `Grade A`

### Important rules
- `if` is **compulsory**, and it must come first.
- `elif` is **optional**, and you can write **many** `elif` blocks.
- `else` is **optional**, and you can have **only one**, at the end.
- Once a condition is True and its block runs, Python **skips all remaining `elif` and `else`** blocks.
- To run an `elif`, the `if` before it must have **failed**.

### Real-time example: ATM-style check
```python
balance = 5000
withdraw = 7000

if withdraw <= balance:
    print("Collect your cash")
else:
    print("Insufficient balance")
```

### Truthy and falsy values in conditions
Python can use almost any value as a condition. Empty or zero values count as `False`:
```python
name = ""
if name:
    print("Name entered")
else:
    print("Name is empty")      # this runs
```

### A useful helper: `eval()`
`eval()` evaluates what the user typed and **automatically works out the data type**.

```python
value = eval(input("Enter something: "))   # user types 25
print(type(value))                          # <class 'int'>
```

> **Safety warning for students:** `eval()` runs whatever text it receives as real Python code. Use it only for practice. In real projects, prefer `int()` or `float()`, which are much safer.
