## 1. Arithmetic, Comparison and Assignment Operators

An **operator** is a symbol that tells Python to do something with values. The values it works on are called **operands**.

```python
result = 10 + 5
```
Here `+` is the operator, and `10` and `5` are the operands.

### A. Arithmetic operators (maths)

- `+` addition
- `-` subtraction
- `*` multiplication
- `/` division (always gives a **float**)
- `//` floor division (drops the decimal part)
- `%` modulus (gives the **remainder**)
- `**` power (exponent)

```python
a = 17
b = 5

print(a + b)    # 22
print(a - b)    # 12
print(a * b)    # 85
print(a / b)    # 3.4
print(a // b)   # 3   (how many times 5 fits fully into 17)
print(a % b)    # 2   (what is left over)
print(a ** 2)   # 289 (17 squared)
```

**Real-life example:** you have 17 chocolates and 5 friends.
- `17 // 5` → each friend gets **3** chocolates.
- `17 % 5` → **2** chocolates are left over.

**Handy trick:** use `%` to check even or odd.
```python
number = 8
print(number % 2)   # 0 → even number (no remainder)
```

### B. Comparison (relational) operators

Comparison operators **compare values** (not data types). They always return either `True` or `False`.

- `==` equal to
- `!=` not equal to
- `>` greater than
- `>=` greater than or equal to
- `<` less than
- `<=` less than or equal to

```python
print(4 == 5)    # False
print(3 != 3)    # False
print(5 > 3)     # True
print(3 >= 3)    # True
print(3 < 1)     # False
print(3 <= 1)    # False
```

Because they compare **values**, not data types:
```python
print(45 == 45.0)   # True (same value, even though int vs float)
```

> **Common mistake:** `=` and `==` are **not the same**.
> - `=` **assigns** a value: `age = 20`
> - `==` **compares** two values: `age == 20`

### C. Assignment operators

The `=` operator **assigns** a value to a variable. Python runs the **right side first**, then stores the result in the **left side** variable.

```python
a = 10
b = a + 10
print(b)    # 20
```
```python
a = 5
a = a + 10
print(a)    # 15
```

**Shortcut (compound) assignment operators:** instead of writing `a = a + 10`, you can write `a += 10`. This works for every arithmetic operator.

- `+=` → `a += 5` is the same as `a = a + 5`
- `-=` → `a -= 5` is the same as `a = a - 5`
- `*=` → `a *= 5` is the same as `a = a * 5`
- `/=` → `a /= 5` is the same as `a = a / 5`
- `//=`, `%=`, `**=` work the same way

```python
score = 50
score += 10     # 60
score -= 5      # 55
score *= 2      # 110
print(score)    # 110
```
