## 9. Nested Loops

### What is a nested loop?
A **nested loop** is a loop **inside another loop**.

Real-life example: a **clock**. For every **1 hour** (outer loop), the **minute hand goes around 60 minutes** (inner loop). The inner loop completes fully before the outer loop moves one step.

### How it runs
- The **outer** loop picks the first value.
- The **inner** loop runs **completely** for that value.
- Then the outer loop moves to the next value, and the inner loop starts again from the beginning.

```python
for i in range(1, 4):
    for j in range(1, 3):
        print("i =", i, "j =", j)
```
```
i = 1 j = 1
i = 1 j = 2
i = 2 j = 1
i = 2 j = 2
i = 3 j = 1
i = 3 j = 2
```
The outer loop runs 3 times, and the inner loop runs 2 times for each, so there are **3 × 2 = 6** prints in total.

### Real-time example: multiplication tables 1 to 3
```python
for i in range(1, 4):
    for j in range(1, 6):
        print(i, "x", j, "=", i * j)
    print("-----")
```

### Real-time example: star pattern
```python
for i in range(1, 6):
    for j in range(i):
        print("*", end=" ")
    print()
```
```
* 
* * 
* * * 
* * * * 
* * * * * 
```
- `end=" "` keeps the stars on the **same line**.
- The empty `print()` moves to the **next line** after each row.

### Real-time example: seating chart
```python
for row in range(1, 4):
    for seat in range(1, 5):
        print(f"Row {row} - Seat {seat}")
```

### Tips
- Indentation is critical. The inner loop is indented once more than the outer loop.
- `break` in an inner loop stops **only the inner loop**, not the outer one.
- Nested loops can be slow for big data, because the work multiplies (100 × 100 = 10,000 rounds).
