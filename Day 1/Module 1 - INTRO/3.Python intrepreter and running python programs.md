## 3. Python Interpreter and Running Python Programs

### What is the interpreter?
The **interpreter** is the program that reads your Python code and executes it. When you "install Python", you are mainly installing this interpreter.

### Three ways to run Python code

**1. Interactive mode (type and see the result instantly)**
Open the terminal, type `python`, and you will see the `>>>` prompt:
```python
>>> 2 + 3
5
>>> print("Hi")
Hi
>>> exit()
```
This is like a calculator. It is perfect for quick experiments.

**2. Script mode (save code in a file and run it)**
Create a file named `hello.py`:
```python
name = "Priya"
print("Hello,", name)
```
Run it from the terminal:
```bash
python hello.py
```

**3. Notebook mode (Jupyter)**
Write code in a cell and press **Shift + Enter** to run it.

### The `print()` function (your first friend)

`print()` is a **function**. It shows output on the screen.

```python
print("Sai")        # text needs quotes
print(12)           # numbers do NOT need quotes
print('Single')     # single quotes work
print("Double")     # double quotes work
print('''Triple''') # triple quotes work too
```

**Printing multiple values:**
```python
print(1, 2, 3)
```
```
1 2 3
```
By default, Python puts a **space** between values. This is called the **separator**. You can change it using `sep`:

```python
print(1, 2, 3, sep=",")
```
```
1,2,3
```

```python
print("2025", "01", "15", sep="-")
```
```
2025-01-15
```

**Bonus:** `end` controls what comes at the *end* of the print (default is a new line):
```python
print("Hello", end=" ")
print("World")
```
```
Hello World
```
