# 5. Comments and Docstrings

### Comments
A **comment** is a note written for humans. Python **ignores it completely** when running the code. It does not change the output at all, and it exists purely for the coder's understanding.

**Why use comments?**
- To explain what the code does
- To make code readable for teammates (and for yourself, three months later!)
- To temporarily disable a line while testing

**Single-line comment** uses `#`:
```python
# This line calculates the total price
total = 250 + 50   # price + delivery charge
```

**Multi-line comment** uses triple quotes (`'''` or `"""`). The quotes must be **three**, not two:
```python
"""
This is a multi-line comment.
It can span as many lines as you want.
"""
print("Hello")
```

> **Small technical truth for curious students:** Triple-quoted text is technically a *string* that isn't stored in any variable, so Python ignores it. Many developers use `#` on each line for real comments, and keep triple quotes for docstrings.

### Docstrings
A **docstring** is a special triple-quoted string written as the *first line inside a function, class or module*. It describes **what that function does**. Unlike a normal comment, Python **keeps** the docstring, and you can read it later.

```python
def add(a, b):
    """Returns the sum of two numbers."""
    return a + b

print(add(3, 4))        # 7
print(add.__doc__)      # Returns the sum of two numbers.
help(add)               # shows the docstring neatly
```

**Quick difference to remember:**
- Comment (`#`) is for developers reading the code. Python throws it away.
- Docstring (`""" """`) is documentation. Python stores it, and tools like `help()` can display it.
