## 6. Variables and Naming Conventions

### First, understand "values"
Values in Python are of two broad kinds:

1. **Numeric:** any real number, without or with a decimal. No quotes needed.
   ```python
   9
   120
   40000
   10.234
   1.03
   ```
2. **Non-numeric (text):** letters, letters + numbers, or special characters. Must be in **quotes**.
   ```python
   "Siva"
   "Siva123"
   "Siva-123"
   "?"
   ```

   ### What is a variable?
A **variable** is a **named box in your computer's memory (RAM)** where you store a value.

Real-life example: you have a box in your cupboard labelled "Rice". The label is the variable name, and the rice inside is the value.

```python
x = 12
```
- `x` is the **variable name**
- `=` is the **assignment operator** (it puts the value into the variable)
- `12` is the **value**

> Note: `=` does **not** mean "equal" like in maths. It means "store this value in this variable".

### What happens behind the scenes?
Python first evaluates the **right side**, then stores the result in the **left side** name.

```python
x = 10 + 5
print(x)   # 15
```

Every value in Python is stored in an **object**. An object has:
- a **value** (what is stored, e.g. `12`)
- a **type** (what kind of data, e.g. `int`)
- an **address** (where it lives in memory)

Python creates the object based on the **value**, *not* on the variable name.

### Checking the address with `id()`
```python
a = 10
print(id(a))   # prints a memory address number
```

### Reassigning a variable
```python
a = 10
a = 20
print(a)   # 20
```
The **latest value wins**. The old value is discarded.

### Assigning multiple variables
Both ways below are correct:
```python
a = 10
b = 20
```
```python
a, b = 10, 20
```
Same value to several variables:
```python
x = y = z = 0
```
Swapping two values (a Python favourite!):
```python
a, b = 10, 20
a, b = b, a
print(a, b)   # 20 10
```

### Deleting a variable with `del`
```python
a = 10
del a          # deletes one variable
print(a)       # NameError: name 'a' is not defined
```
```python
b, c = 1, 2
del b, c       # deletes multiple variables
```

### Rules for naming variables

A variable name is also called an **identifier**.

1. It must **start with a letter** (a-z, A-Z) or an **underscore** `_`.
2. It **cannot start with a number**.
3. It can contain letters, numbers and underscores, but **no spaces** and **no other special characters** (like `@`, `#`, `-`, `$`).
4. It **cannot be a keyword** (reserved word like `if`, `for`, `class`, `True`).
5. It is **case-sensitive**.

```python
name = "Asha"        # valid
_age = 25            # valid
student1 = "Ravi"    # valid
total_marks = 450    # valid

1student = "Ravi"    # invalid, starts with a number
my name = "Asha"     # invalid, has a space
my-name = "Asha"     # invalid, has a hyphen
class = 10           # invalid, 'class' is a keyword
```

To see all Python keywords:
```python
import keyword
print(keyword.kwlist)
```

### Naming conventions (good habits, not strict rules)
- Use **snake_case**: lowercase words joined by underscores → `student_name`, `total_marks`
- Choose **meaningful names**: `price` is better than `p`
- Constants (values that shouldn't change) are written in CAPITALS: `PI = 3.14`

```python
# Bad
x = 500
y = 18

# Good
monthly_salary = 500
tax_percent = 18
```

### Public and private variables
- **Public variable:** starts with a letter. This is the normal kind, e.g. `a1 = 45`.
- **Private variable:** starts with an underscore, e.g. `_a = 45`. This is a signal to other programmers that the variable is meant for internal use and should be left alone.

> **Trainer tip:** In Python, the underscore is a *convention*, not true security. Python won't stop you from reading `_a`, but it tells everyone "please don't touch this".
