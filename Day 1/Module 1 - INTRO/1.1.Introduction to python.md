## 1. Introduction to Python

### What is Python?
Python is a **high-level, general-purpose programming language**. It was created by **Guido van Rossum** and first released in **1991**.

Think of it like this: if other programming languages are like writing instructions in formal legal English, Python is like explaining the same thing to a friend in plain words. It reads almost like English.

```python
print("Hello, welcome to Python!")
```

That is a complete program. In some other languages this would take 5 to 6 lines.

### Advantages

- **Open source and free.** Anyone can download, use and even contribute to it.
- **Simple syntax.** The rules are few and easy, so beginners learn faster.
- **Dynamically typed.** You don't have to declare "this is a number" or "this is text". Python figures it out.
- **Interpreted language.** Python runs your code line by line (more on this below).
- **High-level language.** You don't worry about memory management or hardware details. Python handles that for you.
- **Procedural.** The program works step by step, following a procedure, like a recipe.
- **Platform independent.** The same code runs on Windows, Mac and Linux without changes.
- **Huge library support.** Different jobs have different libraries: data analysis (Pandas), AI/ML (scikit-learn, TensorFlow), web (Django, Flask), automation (Selenium).

### Interpreted vs Compiled (important interview question!)

Real-life example: imagine you have a speech in another language.

- **Compiled language (like Java, C):** A translator first translates the *whole* speech, then hands you the full translated copy. If there is a mistake anywhere, you find out before the speech starts.
- **Interpreted language (like Python):** A translator translates *sentence by sentence while you speak*. If sentence 5 has a problem, sentences 1 to 4 were already delivered, and then the translator stops.

```python
print("Line 1")
print("Line 2")
print(10 / 0)      # Error here!
print("Line 4")    # This never runs
```

**Output:**
```
Line 1
Line 2
ZeroDivisionError: division by zero
```

Python executed lines 1 and 2, hit the error on line 3, and stopped there. Line 4 never ran. Once you fix the error, the program runs further.
