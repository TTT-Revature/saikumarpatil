## 4. Python Syntax and Indentation

### What is syntax?
Syntax means the **grammar rules** of a programming language. Just like English needs correct grammar to make sense, Python needs correct syntax or it shows a `SyntaxError`.

### What is indentation?
Indentation means the **spaces at the start of a line**. In most languages indentation is just for neatness. In Python, **indentation is part of the rule**. It tells Python which lines belong together.

Real-life example: think of a school timetable.
```
Monday
    Period 1: Maths
    Period 2: Science
Tuesday
    Period 1: English
```
The indented lines belong to the day above them. Python works the same way.

```python
age = 20
if age >= 18:
    print("You can vote")       # belongs to the if
    print("Please carry ID")    # belongs to the if
print("Thank you")              # runs always (not indented)
```

### Wrong indentation → Error
```python
if age >= 18:
print("You can vote")   # IndentationError!
```
```
IndentationError: expected an indented block
```

### Golden rules
- Use **4 spaces** for each level of indentation (standard practice).
- Don't mix tabs and spaces in the same file.
- Every line inside a block must have the *same* indentation.
- A line ending with a colon `:` (like `if`, `for`, `while`, `def`) is followed by an indented block.

### Other basic syntax points
- Python is **case-sensitive**: `Name` and `name` are different.
- No semicolons are needed at the end of lines.
- One statement per line is the normal practice.

```python
name = "Ravi"
Name = "Kumar"
print(name)   # Ravi
print(Name)   # Kumar
```
