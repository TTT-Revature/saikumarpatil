## 2. Installing Python and Setting Up the Development Environment

### Step 1: Install Python
1. Go to the official website: **python.org** → Downloads.
2. Download the latest stable version for your OS.
3. **Windows users:** during installation, tick the box **"Add Python to PATH"**. This is the most commonly missed step!
4. Click Install.

### Step 2: Verify the installation
Open Command Prompt (Windows) or Terminal (Mac/Linux) and type:

```bash
python --version
```

On Mac/Linux you may need `python3 --version`. If you see something like `Python 3.12.x`, you are ready.

### Step 3: Choose where to write your code

There are several tools (called IDEs or editors) for writing Python:

- **IDLE** stands for *Integrated Development and Learning Environment*. It comes bundled with Python, which makes it good for the very first day.
- **Anaconda** is a bundle that gives you Python plus many data science tools. It includes **Spyder** and **Jupyter Notebook**.
- **Jupyter Notebook** lets you write code in small blocks (cells) and see the output right below each cell. It is great for learning and for AI/data work. Files are saved with the **.ipynb** extension, which stands for *Interactive Python Notebook*.
- **VS Code / PyCharm** are professional editors widely used in companies.

### Handy Jupyter tips

**Where is my file saved?** Type this in a cell and run it:
```python
pwd
```
`pwd` means *Present Working Directory*. It shows the folder your notebook is currently using.
