## 7. Basic Data Types

A **data type** tells Python **what kind of value** is stored. Think of it as the type of container: a water bottle holds liquids, a lunch box holds solid food. Different containers for different content.

Python data types are grouped into two families:

- **Fundamental data types:** store **only one value** at a time.
**1. Integer (`int`)** is a whole number, with no decimal, positive or negative.
```python
age = 42
temperature = -5
```

**2. Float (`float`)** is a number with a decimal point.
```python
price = 42.3
height = 5.8
```

**3. Complex (`complex`)** is a number with a real and an imaginary part (used in engineering and science).
```python
z = 2 + 3j
print(z.real)   # 2.0
print(z.imag)   # 3.0
```

**4. Boolean (`bool`)** is either `True` or `False`. The first letter **must be capital**.
```python
is_logged_in = True
has_paid = False
```
Real-life use: a light switch is either ON or OFF, and a ticket is either booked or not booked.

**5. String (`str`)** is text. It can be a mix of letters, numbers and symbols, and it is written inside quotes.
```python
name = "Siva"
city = 'Chennai'
```
A string is a **single value even though it has multiple characters**. `"Siva"` is one value stored in one variable.

**Finding the number of characters with `len()`:**
```python
name = "Siva"
print(len(name))   # 4
```

### B. Advanced data types (containers)

These can hold many values in one variable. You will study each one deeply in Module 4. For now, here is the quick introduction.

**List** uses square brackets `[ ]` and is **mutable**.
```python
fruits = ["apple", "banana", "mango"]
```

**Tuple** uses round brackets `( )` and is **immutable**.
```python
location = (13.08, 80.27)
```

**Set** uses curly brackets `{ }` and is **mutable**. It stores unique values only.
```python
numbers = {1, 2, 3}
```

**Dictionary (`dict`)** is **mutable**. It stores data as key-value pairs.
```python
student = {"name": "Asha", "age": 21}
```

### Quick summary for students
- `int` → `42`
- `float` → `42.3`
- `complex` → `2+3j`
- `bool` → `True` / `False`
- `str` → `"Hello"`
- `list` → `[1, 2, 3]`
- `tuple` → `(1, 2, 3)`
- `set` → `{1, 2, 3}`
- `dict` → `{"a": 1}`
