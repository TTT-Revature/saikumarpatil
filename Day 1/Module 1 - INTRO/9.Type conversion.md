## 9. Type Conversion (Type Casting)

### What is it?
**Type conversion** (also called **type casting**) means converting a value from **one data type to another**.

### Why do we need it? The `input()` story

The `input()` function takes data from the user. **Important rule: `input()` always gives you a string**, no matter what the user types.

```python
age = input("Enter your age: ")   # user types 24
print(age)           # 24
print(type(age))     # <class 'str'>   ← it's text, not a number!
```

So this will fail:
```python
age = input("Enter your age: ")
print(age + 1)    # TypeError: can only concatenate str (not "int") to str
```

The fix is type casting:
```python
age = int(input("Enter your age: "))
print(age + 1)    # 25
```

### Conversion functions

For fundamental types: `int()`, `float()`, `bool()`, `str()`
For advanced types: `list()`, `tuple()`, `set()`, `dict()`

### Converting an `int` to other types
```python
a = 10
print(float(a))   # 10.0
print(bool(a))    # True
print(str(a))     # '10'
```
`bool(0)` is `False`, and `bool` of any other number is `True`.

### Converting a `float` to other types
```python
b = 0.96
print(int(b))     # 0   ← decimal part is dropped (NOT rounded)
print(int(9.99))  # 9
print(bool(0.001))# True ← anything other than 0 is True
print(bool(0.0))  # False
```

### Converting a `str` to other types
```python
print(int("25"))      # 25
print(float("3.14"))  # 3.14
print(int("abc"))     # ValueError: invalid literal for int()
print(int("3.5"))     # ValueError, you must use float("3.5") first
```
A string can be converted to `int` or `float` **only if it looks like a number**.

### Converting to `bool`: what is True and what is False?
These are **False**: `0`, `0.0`, `""` (empty string), `[]` (empty list), `{}`, `()`, `None`
Everything else is **True**.

```python
print(bool(""))        # False
print(bool("hello"))   # True
print(bool([]))        # False
print(bool([0]))       # True  (the list is not empty)
```

### Converting between containers
```python
my_list = [1, 2, 2, 3]
print(tuple(my_list))   # (1, 2, 2, 3)
print(set(my_list))     # {1, 2, 3}  ← duplicates removed!
print(list("hello"))    # ['h', 'e', 'l', 'l', 'o']
```

### Real-time example: simple bill calculator
```python
price = float(input("Enter price of one item: "))
quantity = int(input("Enter quantity: "))

total = price * quantity
print("Total bill:", total)
```
If we didn't use `float()` and `int()`, Python would treat both inputs as text, and the multiplication would not behave as expected.

> **Tip:** Python stores a value only when a variable name is given and the `=` symbol is used. Without that, the value is shown and then lost.
