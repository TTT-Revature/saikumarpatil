## 10. `type()` and Basic Object Inspection 📖 (Self-read)

When you are not sure what is inside a variable, **inspect it**. Python gives you simple functions for this.

### `type()`: what kind of data is this?
```python
a = 42
b = 42.5
c = "Hello"
d = True
e = [1, 2, 3]

print(type(a))   # <class 'int'>
print(type(b))   # <class 'float'>
print(type(c))   # <class 'str'>
print(type(d))   # <class 'bool'>
print(type(e))   # <class 'list'>
```

### `id()`: where is it stored?
```python
a = 10
print(id(a))
```

### `len()`: how many characters or items?
```python
print(len("Python"))        # 6
print(len([10, 20, 30]))    # 3
```
`len()` works on strings and also on containers like lists, tuples, sets and dicts. It does **not** work on plain numbers (`len(10)` gives a TypeError).

### `isinstance()`: a safer check
```python
age = 25
print(isinstance(age, int))     # True
print(isinstance(age, str))     # False
```

### `dir()` and `help()`: what can this object do?
```python
name = "python"
print(dir(name))        # lists all the things a string can do
help(str.upper)         # explains one method
```

### Handy example: debugging with `type()`
```python
user_input = input("Enter a number: ")
print(type(user_input))      # <class 'str'>, so convert it first!
number = int(user_input)
print(type(number))          # <class 'int'>
```
