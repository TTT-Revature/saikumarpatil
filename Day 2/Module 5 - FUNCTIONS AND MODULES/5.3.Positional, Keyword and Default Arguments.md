## 3. Positional, Keyword and Default Arguments

### A. Positional arguments
When you call a function, Python matches arguments to parameters **by position**: the first argument goes to the first parameter, and so on.

```python
def greet(name, msg):
    print("Hello", name, msg)

greet("Sai", "good morning")
```
```
Hello Sai good morning
```
Swapping the order changes the result:
```python
greet("good morning", "Sai")    # Hello good morning Sai
```

### B. Keyword arguments
When you call a function, you can name the parameter explicitly. Now **order does not matter**.

```python
def greet(name, msg):
    print("Hello", name, msg)

greet(msg="good morning", name="Sai")
```
```
Hello Sai good morning
```

**Mixing both:** positional arguments must come **first**, then keyword arguments.
```python
greet("Sai", msg="good morning")       # correct
# greet(name="Sai", "good morning")    # SyntaxError
```

> **Key difference to remember:** When **creating** a function, there is no difference between positional and keyword parameters. When **calling** it, the difference is in how you pass the values.

### C. Default arguments
A parameter can have a **default value** using `=`. If the caller doesn't give a value, the default is used.

```python
def greet(name, msg="good night"):
    print("Hello", name, msg)

greet("Sai", "good morning")   # Hello Sai good morning   (argument given → uses it)
greet("Sai")                   # Hello Sai good night     (not given → uses default)
```

**Rules:**
- If the value is given in the call, Python **uses the given value**.
- If it is not given, Python **automatically takes the default**.
- Parameters with defaults must come **after** parameters without defaults.

```python
def greet(name, msg="good night"):    # correct
# def greet(msg="good night", name):  # SyntaxError
```

### Real-time example: a delivery charge
```python
def checkout(total, delivery=40):
    print(f"Total payable: Rs.{total + delivery}")

checkout(500)              # Total payable: Rs.540   (default delivery)
checkout(500, delivery=0)  # Total payable: Rs.500   (free delivery)
```

> **Watch out (advanced):** Never use a **mutable** default like `def f(items=[])`. The same list is shared between every call. Use `None` instead:
> ```python
> def add_item(item, items=None):
>     if items is None:
>         items = []
>     items.append(item)
>     return items
> ```
