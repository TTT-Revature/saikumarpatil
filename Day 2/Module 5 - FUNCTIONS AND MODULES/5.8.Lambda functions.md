## 8. Lambda Functions

### What is a lambda?
A **lambda** is a **small, unnamed function** written in one line. It is useful when you need a simple function only once, for example inside `map()`, `filter()` or `sorted()`.

**Syntax:**
```python
lambda parameters: expression
```

```python
square = lambda x: x * x
print(square(5))          # 25

add = lambda a, b: a + b
print(add(3, 4))          # 7
```

The version above is the same as writing:
```python
def square(x):
    return x * x
```

### A lambda with a condition
```python
check = lambda n: "Even" if n % 2 == 0 else "Odd"
print(check(7))           # Odd
```

### Where lambdas shine: inside other functions
```python
students = [("Asha", 85), ("Ravi", 62), ("Meena", 92)]

# sort by marks (the second item of each tuple)
ranked = sorted(students, key=lambda s: s[1], reverse=True)
print(ranked)
# [('Meena', 92), ('Asha', 85), ('Ravi', 62)]
```

### When not to use lambda
- If the logic needs more than one line, use `def`.
- If the function needs a name and will be used many times, use `def`.
- Readability matters more than being short.
