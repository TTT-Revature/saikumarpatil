## 9. `map()`, `filter()` and `sorted(key=...)` 

### Higher-order functions
A **higher-order function** is a function that takes **another function** as input, or returns one. Python has three important built-in ones for working with sequences: `map`, `filter` and `reduce`.

### A. `map()`: transform every item
`map(function, iterable)` applies a function to **each element** and gives you the transformed results. It is a neat alternative to a `for` loop, and it is often faster.

```python
def cube(x):
    return x * x * x

print(cube(2))                       # 8   (for a single value)

nums = [1, 2, 3, 4]
result = list(map(cube, nums))       # for multiple values
print(result)                        # [1, 8, 27, 64]
```

> **Why `list(...)`?** `map()` returns a special **iterator** object, which you cannot read directly. Wrapping it in `list()` turns it into a list you can see.

Equivalent loop:
```python
result = []
for n in nums:
    result.append(cube(n))
```

**Using `map()` with a lambda:**
```python
prices = [100, 250, 50]
with_gst = list(map(lambda p: p * 1.18, prices))
print(with_gst)                      # [118.0, 295.0, 59.0]
```

**Using `map()` with two lists:**
```python
a = [1, 2, 3]
b = [10, 20, 30]
print(list(map(lambda x, y: x + y, a, b)))     # [11, 22, 33]
```

### B. `filter()`: keep only the items that pass a test
`filter(predicate, iterable)` keeps only the items for which the **predicate** returns `True`.

- A **predicate** is a function that returns a **boolean** (`True` or `False`).
- Result: a new sequence containing **only** the elements that meet the predicate.

```python
def is_even(n):
    return n % 2 == 0

nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(is_even, nums))
print(evens)                         # [2, 4, 6]
```

With a lambda:
```python
marks = [35, 72, 48, 90, 28]
passed = list(filter(lambda m: m >= 40, marks))
print(passed)                        # [72, 48, 90]
```

> **Remember:** `filter` returns **fewer** (or the same number of) items. `map` returns **the same number** of items, transformed.

### C. `reduce()`: combine all items into one value
`reduce()` is in the `functools` module. It takes a function and repeatedly combines the items two at a time, until only one value remains.

```python
from functools import reduce

nums = [1, 2, 3, 4]
total = reduce(lambda a, b: a + b, nums)
print(total)                         # 10
```
How it works: `((1 + 2) + 3) + 4 = 10`.

### D. `sorted(key=...)`: sort by your own rule
`sorted()` can take a `key` function that tells Python **what to compare**.

```python
words = ["banana", "kiwi", "apple", "fig"]

print(sorted(words))                 # ['apple', 'banana', 'fig', 'kiwi']  (alphabetical)
print(sorted(words, key=len))        # ['fig', 'kiwi', 'apple', 'banana']  (by length)
```

Sorting a list of dictionaries by a field:
```python
employees = [
    {"name": "Asha", "salary": 50000},
    {"name": "Ravi", "salary": 40000},
    {"name": "Meena", "salary": 55000},
]

by_salary = sorted(employees, key=lambda e: e["salary"], reverse=True)
for e in by_salary:
    print(e["name"], e["salary"])
```

### Comparing the three together
```python
numbers = [1, 2, 3, 4, 5, 6]

doubled = list(map(lambda x: x * 2, numbers))        # [2, 4, 6, 8, 10, 12]
evens = list(filter(lambda x: x % 2 == 0, numbers))  # [2, 4, 6]
total = sum(numbers)                                  # 21
```

### Real-time example: clean and filter user data
```python
raw_emails = ["  Asha@Mail.com ", "", "ravi@mail.com", "  ", "meena@mail.com"]

cleaned = list(map(lambda e: e.strip().lower(), raw_emails))
valid = list(filter(lambda e: "@" in e, cleaned))
print(valid)     # ['asha@mail.com', 'ravi@mail.com', 'meena@mail.com']
```
