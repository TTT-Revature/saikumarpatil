## 1. Defining and Calling Functions

### Why do we need functions?
Imagine you need to print a welcome banner in ten places in your program. Without functions, you copy the same code ten times. If the banner changes, you must edit ten places. A **function** lets you write the code **once**, give it a name, and **call** it wherever you need it.

This is the **DRY principle**: *Don't Repeat Yourself*.

Real-life example: a **washing machine programme**. You press the "Cotton" button and the machine runs a set of steps. You don't rewrite the steps each time you do laundry.

### Defining a function
**Syntax:**
```python
def function_name():
    # body (indented)
```
- `def` is the keyword that starts a function
- the name follows the same rules as variable names
- the brackets `()` are a must, even if empty
- the colon `:` ends the first line, and the body is indented

```python
def greet():
    print("Good morning, students!")
```

### Calling a function
A function does **nothing** until you call it. A call means writing the name with brackets.

```python
greet()          # Good morning, students!
greet()          # Good morning, students!
```

> **Common mistake:** `greet` (without brackets) refers to the function object itself and does **not** run it.

### Functions with calculations
```python
def add_numbers():
    a = 45
    b = 50
    c = a + b
    print(c)

add_numbers()    # 95
```

### Calling a function before defining it
Python reads the code from top to bottom. The function must be **defined before** it is called.
```python
show()           # NameError: name 'show' is not defined

def show():
    print("Hello")
```

### Real-time example: a reusable price calculator
```python
def calculate_bill():
    price = 250
    quantity = 4
    total = price * quantity
    print("Total bill:", total)

calculate_bill()      # Total bill: 1000
calculate_bill()      # Total bill: 1000
```
