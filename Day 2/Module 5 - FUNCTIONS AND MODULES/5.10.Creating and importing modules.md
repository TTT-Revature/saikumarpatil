## 10. Creating and Importing Modules

### What is a module?
A **module** is simply a **Python file (`.py`)** that contains functions, classes or variables you want to reuse in other programs.

Real-life example: a **toolbox**. You keep your hammer, screwdriver and spanner in one box, and you can take the whole box to any job. A module is a toolbox of related code.

### Creating a module
Create a file named `mathutils.py`:
```python
# mathutils.py

PI = 3.14159

def add(a, b):
    return a + b

def circle_area(radius):
    return PI * radius * radius
```

Now any other file in the **same folder** can use it.

### Importing a module
```python
# main.py
import mathutils

print(mathutils.add(10, 5))           # 15
print(mathutils.circle_area(2))       # 12.56636
print(mathutils.PI)                   # 3.14159
```
To use something from a module, write **`module_name.item_name`**. The dot tells Python "look inside this module".

### Built-in modules
Python comes with hundreds of ready-made modules. You import them the same way.
```python
import math
import random

print(math.sqrt(16))            # 4.0
print(math.factorial(5))        # 120
print(random.randint(1, 6))     # a random number from 1 to 6
```

### Checking what a module contains
```python
import math
print(dir(math))                # lists everything inside the module
help(math.sqrt)                 # explains one function
```

### Module names
- Keep module names short, lowercase and without spaces, for example `mathutils.py` or `bank_tools.py`.
- Don't name your file the same as a built-in module (for example `random.py` or `math.py`). If you do, Python imports your file instead of the real module, and things break.

### Real-time example: a reusable tax module
```python
# tax.py
GST_RATE = 0.18

def add_gst(amount):
    return amount + amount * GST_RATE
```
```python
# billing.py
from tax import add_gst

print(add_gst(1000))       # 1180.0
```
