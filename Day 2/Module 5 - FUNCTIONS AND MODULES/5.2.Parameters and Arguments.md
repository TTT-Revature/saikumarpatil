## 2. Parameters and Arguments

### Parameters vs arguments
These two words are often mixed up. Remember this:
- **Parameter:** the variable name written **in the function definition** (a placeholder).
- **Argument:** the actual value **passed in the function call**.

Real-life example: a **form** with a blank box labelled "Name". The box is the **parameter**. When you write "Asha" in it, "Asha" is the **argument**.

```python
def greet(name):          # name → parameter
    print("Hello", name)

greet("Asha")             # "Asha" → argument
greet("Ravi")             # "Ravi" → argument
```

### Multiple parameters
```python
def add(a, b):
    print(a + b)

add(10, 20)     # 30
add(5, 7)       # 12
```

### What happens during a call?
When you call `greet("Asha")`, Python:
1. creates the variable `name` inside the function
2. stores the value `"Asha"` in it
3. runs the function body
4. **discards** `name` after the function finishes

### Passing the wrong number of arguments
```python
def add(a, b):
    print(a + b)

add(10)         # TypeError: add() missing 1 required positional argument: 'b'
```

### Real-time example: personalised certificate
```python
def give_certificate(student, course, grade):
    print(f"This certifies that {student} completed {course} with grade {grade}.")

give_certificate("Asha", "Python Basics", "A")
```
