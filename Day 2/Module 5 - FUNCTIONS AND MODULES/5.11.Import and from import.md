## 11. `import` and `from ... import`

### Three ways to import

**1. Import the whole module**
```python
import math
print(math.sqrt(49))          # 7.0
```
Advantage: clear where each function comes from. Disadvantage: you type the module name every time.

**2. Import specific items**
```python
from math import sqrt, pi
print(sqrt(49))               # 7.0
print(pi)                     # 3.141592653589793
```
Advantage: shorter to write. The items can be used directly, without the module name.

**3. Import with an alias**
```python
import numpy as np
import pandas as pd

print(np.array([1, 2, 3]))
```
`as` gives a shorter name. This is a very common convention in data science.

**4. Import everything (avoid this)**
```python
from math import *
print(sqrt(49))
```
This brings everything in, which can overwrite your own names and makes code hard to trace. Use it only in quick experiments.

### Which way to choose?
- `import module` → clearest, best for most code
- `from module import item` → when you use one or two items often
- `import module as alias` → for long module names
- `from module import *` → avoid

### Importing from your own modules
```python
from mathutils import add, circle_area

print(add(2, 3))              # 5
print(circle_area(1))         # 3.14159
```

### What happens when you import?
The first time a module is imported, Python **runs the whole file once**. After that, Python reuses the already-loaded module; it does not run it again.

```python
# greeting.py
print("Greeting module loaded")
```
```python
import greeting        # prints: Greeting module loaded
import greeting        # prints nothing (already loaded)
```

### Real-time example: a small project layout
```
project/
├── main.py
├── mathutils.py
└── tax.py
```
```python
# main.py
from mathutils import add
from tax import add_gst

total = add(100, 50)
print("With GST:", add_gst(total))
```
