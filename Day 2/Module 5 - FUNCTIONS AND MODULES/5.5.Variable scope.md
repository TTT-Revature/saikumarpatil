## 5. Variable Scope

### What is scope?
**Scope** is the part of the program where a variable can be **seen and used**.

Real-life example: a **kitchen**. Ingredients stored in the kitchen can be used only inside the kitchen. Things stored in the **house** can be used by everyone in the house, including the kitchen.

### Local variables
A variable created **inside a function** is a **local variable**. It exists only while the function is running.

```python
def show():
    message = "Inside the function"
    print(message)

show()                 # Inside the function
print(message)         # NameError: name 'message' is not defined
```

### Global variables
A variable created **outside every function** is a **global variable**. Any function can read it.

```python
greeting = "Welcome"          # global

def show():
    print(greeting)           # reads the global variable

show()                        # Welcome
print(greeting)               # Welcome
```

### Local and global with the same name
If a local variable has the same name as a global one, the function uses the **local** version inside itself. The global one is **not changed**.

```python
a = 10                        # global

def change():
    a = 20                    # creates a NEW local variable
    print("Inside:", a)       # 20

change()                      # Inside: 20
print("Outside:", a)          # Outside: 10
```

### Changing a global variable: `global`
To change the global variable from inside a function, declare it with `global`.

```python
a = 10

def change():
    global a
    a = 20

change()
print(a)          # 20
```

> **Good practice:** Avoid `global` where you can. Pass values in as parameters and return results instead. Code is easier to test and debug that way.

### Real-time example: a counter
```python
count = 0                         # global

def increment():
    global count
    count += 1

increment()
increment()
print("Count is", count)          # Count is 2
```

### Quick rule
- Created **inside** a function → **local**, visible only inside.
- Created **outside** every function → **global**, readable everywhere.
- To **change** a global inside a function → use `global`.
