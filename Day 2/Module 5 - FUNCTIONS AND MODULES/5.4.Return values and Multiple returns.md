## 4. Return Values and Multiple Returns

### `print()` vs `return`
This is one of the most important ideas in functions.
- `print()` **shows** a value on the screen. The value is then lost.
- `return` **sends** a value **back** to the caller, so you can store it, reuse it or calculate with it.

```python
def add_show(a, b):
    print(a + b)            # only displays

def add_back(a, b):
    return a + b            # gives the result back

x = add_show(2, 3)          # prints 5
print(x)                    # None  (the function returned nothing)

y = add_back(2, 3)
print(y * 10)               # 50    (we can use the result)
```

### Functions without `return` give `None`
If a function has no `return` statement, Python returns **`None`** automatically.

### Returning multiple values
A function can return several values at once. Python packs them into a **tuple** automatically, and you can unpack them into separate variables.

```python
def calculate(a, b):
    return a + b, a - b, a * b

s, d, p = calculate(10, 5)
print(s, d, p)       # 15 5 50

result = calculate(10, 5)
print(result)        # (15, 5, 50)   ← stored as a tuple
```

### The rule for multiple values
- If the number of variables **matches** the number of values, each one gets a value.
- If the number **does not match**, Python raises a `ValueError`.

```python
a, b = 10, 20, 30     # ValueError: too many values to unpack
```

### Returning early
`return` also **stops the function immediately**.
```python
def check_age(age):
    if age < 18:
        return "Not eligible"
    return "Eligible"

print(check_age(15))   # Not eligible
print(check_age(20))   # Eligible
```

### Real-time example: a result calculator
```python
def analyse_marks(marks):
    total = sum(marks)
    average = total / len(marks)
    highest = max(marks)
    return total, average, highest

total, avg, top = analyse_marks([78, 92, 65, 88])
print(f"Total: {total}, Average: {avg:.2f}, Highest: {top}")
```
