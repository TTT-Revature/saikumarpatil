## 6. `*args` and `**kwargs` 

### The problem
Sometimes you don't know in advance how many arguments a function will receive. For example, a `total()` function may be called with 2 numbers, or with 20.

Python solves this with **arbitrary arguments**.

### A. `*args`: many positional values
`*args` collects **all extra positional arguments into a tuple**. The name `args` is a convention. The `*` is the important part.

```python
def greet(*names):
    for name in names:
        print("Hello", name)

greet("Sai", "Sai Kumar", "Vinayak")
```
```
Hello Sai
Hello Sai Kumar
Hello Vinayak
```

Without the `*`, the function would take only one argument. The notes put it this way: **if `*` is not used, the function does not take multiple arguments.**

```python
def total(*numbers):
    return sum(numbers)

print(total(1, 2))            # 3
print(total(1, 2, 3, 4, 5))   # 15
```

Mixing a normal parameter with `*args`:
```python
def report(title, *scores):
    print(title, sum(scores))

report("Week 1", 50, 60, 70)  # Week 1 180
```

### B. `**kwargs`: many keyword values
`**kwargs` collects **all extra keyword arguments into a dictionary**.

```python
def student_info(**details):
    for key, value in details.items():
        print(f"{key}: {value}")

student_info(name="Asha", age=21, city="Chennai")
```
```
name: Asha
age: 21
city: Chennai
```

### Using both together
Order in the definition must be: normal parameters, then `*args`, then `**kwargs`.
```python
def profile(title, *skills, **info):
    print("Title:", title)
    print("Skills:", skills)
    print("Info:", info)

profile("Developer", "Python", "SQL", city="Chennai", years=3)
```
```
Title: Developer
Skills: ('Python', 'SQL')
Info: {'city': 'Chennai', 'years': 3}
```

### Unpacking with `*` and `**` when calling
You can also use `*` and `**` **in the call** to spread a list or dictionary into separate arguments.
```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))          # 6

config = {"a": 1, "b": 2, "c": 3}
print(add(**config))       # 6
```

### Real-time example: a flexible shopping total
```python
def shopping_total(*prices, tax=0.05):
    subtotal = sum(prices)
    return subtotal + subtotal * tax

print(shopping_total(100, 250, 50))             # 420.0
print(shopping_total(100, 250, tax=0.1))        # 385.0
```
