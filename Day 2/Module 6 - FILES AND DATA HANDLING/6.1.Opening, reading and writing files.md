### Why does this module matter?
So far, all our data disappears when the program ends. Real programs need to **save** data (student marks, bank transactions, logs) and **load** it again later. This module teaches you how to work with files, folders, structured data (JSON, CSV), dates and configuration values.

Real-life comparison: a program's variables are like the notes on a whiteboard, which get erased when the class ends. Files are like a notebook you keep in your bag.

## 1. Opening, Reading and Writing Files

### Step 1: open the file
The built-in function `open()` opens a file and returns a **file object**.

```python
f = open("notes.txt", "r")     # open for reading
print(f.read())
f.close()                      # always close the file when done
```

**Syntax:**
```python
open(filename, mode)
```
- `filename` is the name (or path) of the file
- `mode` says what you want to do: read, write, append and so on

### Reading a file

There are four common ways to read:

```python
f = open("notes.txt", "r")

content = f.read()        # the entire file as ONE string
print(content)

f.close()
```

```python
f = open("notes.txt", "r")
line = f.readline()       # reads ONE line at a time
print(line)
f.close()
```

```python
f = open("notes.txt", "r")
lines = f.readlines()     # all lines as a LIST (each line ends with \n)
print(lines)
f.close()
```

**Most common: loop over the file line by line** (efficient for large files):
```python
f = open("notes.txt", "r")
for line in f:
    print(line.strip())   # strip() removes the \n at the end
f.close()
```

### Writing to a file

```python
f = open("report.txt", "w")     # "w" creates the file, or ERASES it if it exists
f.write("Hello, file!\n")       # write() takes a STRING only
f.write("Second line\n")
f.close()
```

> **Important:** `write()` needs a **string**. Numbers must be converted first:
> ```python
> f.write(str(100))
> ```

`writelines()` writes a list of strings, but it does **not** add new lines for you:
```python
f = open("list.txt", "w")
f.writelines(["Apple\n", "Banana\n", "Mango\n"])
f.close()
```

### Appending to a file
`"a"` adds new content at the **end** without erasing the old content.
```python
f = open("log.txt", "a")
f.write("New entry added\n")
f.close()
```

### Real-time example: a simple marks register
```python
# save marks
f = open("marks.txt", "w")
f.write("Asha,85\n")
f.write("Ravi,72\n")
f.close()

# read them back
f = open("marks.txt", "r")
for line in f:
    name, mark = line.strip().split(",")
    print(f"{name} scored {mark}")
f.close()
```
```
Asha scored 85
Ravi scored 72
```

### Common errors
```python
f = open("missing.txt", "r")     # FileNotFoundError: No such file or directory
```
A missing file, a file that's open in another program, or a folder without permission will raise an error. The `with` statement (Section 3) and `try/except` (Module 7) help you handle these safely.

> **Don't forget to close.** If you forget `close()`, the data may not be saved completely. The `with` statement solves this for you automatically.
