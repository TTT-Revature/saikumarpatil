## 2. File Modes and Text/Binary Files 

### The main modes

- `"r"` read only. File must exist. (default if you write nothing)
- `"w"` write only. **Creates** the file, or **erases** it if it exists.
- `"a"` append. Adds to the end. Creates the file if it doesn't exist.
- `"x"` create only. Fails with an error if the file already exists.
- `"r+"` read and write. File must exist, and you start at the beginning.

Real-life example: opening a notebook.
- `r` → you only read it.
- `w` → you tear out all the pages and start a new notebook with the same name.
- `a` → you keep writing on the last page.
- `x` → you insist on a brand-new notebook. If one already exists, stop.

```python
open("data.txt", "x")     # creates the file
open("data.txt", "x")     # FileExistsError
```

### Text mode vs binary mode
Add `t` (text, the default) or `b` (binary) to the mode.

- **Text mode** (`"r"`, `"w"`, `"rt"`): data is read as **strings**. Used for `.txt`, `.csv`, `.json`, `.py` files.
- **Binary mode** (`"rb"`, `"wb"`): data is read as **bytes** (raw numbers). Used for images, PDFs, audio and video.

```python
with open("photo.jpg", "rb") as f:
    data = f.read()
    print(type(data))        # <class 'bytes'>
    print(len(data))         # total number of bytes
```

```python
with open("copy.jpg", "wb") as f:
    f.write(data)            # copy the bytes to a new file
```

> **Rule of thumb:** If the file is something a human can read in Notepad, use text mode. If it's a picture, video, PDF or music, use binary mode.

### Encoding (important for Indian languages and emojis)
Text files store characters using an **encoding**. Use UTF-8 so that Tamil, Hindi, emojis and other characters are saved correctly:
```python
with open("names.txt", "w", encoding="utf-8") as f:
    f.write("அசோக் \n")
```

### Checking the current position
```python
f = open("notes.txt", "r")
print(f.read(5))     # first 5 characters
print(f.tell())      # current position in the file
f.close()
```

### Real-time example: safe append for a log file
```python
from datetime import datetime

with open("activity.log", "a", encoding="utf-8") as f:
    f.write(f"{datetime.now()} - User logged in\n")
```
Each run adds a new line and keeps the old ones.
