## 4. `pathlib`

### Why pathlib?
File paths are different on Windows (`C:\Users\Asha\data.txt`) and Linux/Mac (`/home/asha/data.txt`). Typing paths as strings and joining them with `+` causes bugs. The `pathlib` module handles all of this for you, and it works on every operating system.

Real-life example: a **postal address**. `pathlib` knows how to write the address correctly for each country, so you just say "the file `data.txt` inside the `reports` folder".

```python
from pathlib import Path
```

### Creating a path
```python
p = Path("reports") / "2025" / "sales.csv"
print(p)              # reports/2025/sales.csv   (Linux/Mac)
                      # reports\2025\sales.csv   (Windows)
```
The `/` operator joins parts of a path. It is the recommended way.

### Useful properties
```python
p = Path("reports/2025/sales.csv")

print(p.name)         # sales.csv     (file name with extension)
print(p.stem)         # sales         (name without extension)
print(p.suffix)       # .csv          (extension)
print(p.parent)       # reports/2025  (the folder it is in)
```

### Checking what exists
```python
p = Path("notes.txt")

print(p.exists())     # True or False
print(p.is_file())    # True if it is a file
print(p.is_dir())     # True if it is a folder
```

### Reading and writing with pathlib
Short helpers for small files:
```python
p = Path("hello.txt")
p.write_text("Hello from pathlib!", encoding="utf-8")
print(p.read_text(encoding="utf-8"))
```

### Creating folders
```python
Path("reports/2025").mkdir(parents=True, exist_ok=True)
```
- `parents=True` creates missing parent folders too
- `exist_ok=True` does not raise an error if the folder already exists

### Listing files
```python
folder = Path("reports")

for item in folder.iterdir():             # everything inside
    print(item.name)

for csv_file in folder.glob("*.csv"):     # only CSV files
    print(csv_file)

for csv_file in folder.rglob("*.csv"):    # CSV files in all sub-folders
    print(csv_file)
```

### Useful locations
```python
print(Path.cwd())      # current working directory (where the program runs)
print(Path.home())     # your user's home folder
```

### Real-time example: organise downloads by file type
```python
from pathlib import Path

downloads = Path("downloads")

for file in downloads.iterdir():
    if file.is_file():
        target = downloads / file.suffix.lstrip(".").upper()
        target.mkdir(exist_ok=True)
        print(f"{file.name} → {target}")
```

> **Trainer tip:** Compare `os.path.join("reports", "2025", "sales.csv")` with `Path("reports") / "2025" / "sales.csv"`. Students will see why `pathlib` is easier to read.
