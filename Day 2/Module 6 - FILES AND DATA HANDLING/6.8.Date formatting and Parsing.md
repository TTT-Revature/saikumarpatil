## 8. Date Formatting and Parsing

### Two directions again
- **Formatting** (`strftime`): date object → text, for display. Example: a date to `15 Aug 1999`.
- **Parsing** (`strptime`): text → date object, for calculation. Example: `"15-08-1999"` to a date.

The letters `str` in the names mean "string", and `f` means "format" and `p` means "parse".

### Formatting with `strftime()`
```python
from datetime import datetime

now = datetime(2026, 11, 17, 14, 30, 5)

print(now.strftime("%d/%m/%Y"))           # 17/11/2026
print(now.strftime("%d %B %Y"))           # 17 November 2026
print(now.strftime("%A, %d %b %Y"))       # Tuesday, 17 Nov 2026
print(now.strftime("%H:%M:%S"))           # 14:30:05
print(now.strftime("%I:%M %p"))           # 02:30 PM
```

### Common format codes

- `%d` day (01 to 31)
- `%m` month as a number (01 to 12)
- `%Y` year with 4 digits
- `%y` year with 2 digits
- `%B` full month name (November)
- `%b` short month name (Nov)
- `%A` full weekday name (Tuesday)
- `%a` short weekday name (Tue)
- `%H` hour in 24-hour format
- `%I` hour in 12-hour format
- `%M` minutes
- `%S` seconds
- `%p` AM or PM
- `%j` day of the year (001 to 366)

### Parsing with `strptime()`
Tell Python the format of the text, and it converts the text into a date or datetime object.

```python
from datetime import datetime

d = datetime.strptime("15-08-1999", "%d-%m-%Y")
print(d)                    # 1999-08-15 00:00:00
print(d.year)               # 1999
```

```python
d = datetime.strptime("15 Aug 1999 10:45", "%d %b %Y %H:%M")
print(d)                    # 1999-08-15 10:45:00
```

If the text doesn't match the format, you get an error:
```python
datetime.strptime("1999-08-15", "%d-%m-%Y")   # ValueError
```

### ISO format (the standard)
ISO 8601 (`YYYY-MM-DD`) is the safest format for storing dates, because it sorts correctly as text.

```python
from datetime import date

d = date.fromisoformat("2026-11-17")
print(d.isoformat())        # 2026-11-17
```

### Real-time example: reading dates from a CSV
```python
import csv
from datetime import datetime

with open("orders.csv", "r", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        order_date = datetime.strptime(row["date"], "%d-%m-%Y")
        print(order_date.strftime("%d %B %Y"), "-", row["item"])
```

### Real-time example: a readable invoice date
```python
from datetime import date

invoice_date = date(2026, 11, 17)
print("Invoice Date:", invoice_date.strftime("%d %B, %Y"))   # Invoice Date: 17 November, 2026
```

### Quick cheat sheet
- Display a date: `strftime("%d %B %Y")`
- Read a date from text: `strptime(text, "%d-%m-%Y")`
- Store a date safely: `isoformat()` (`2026-11-17`)
