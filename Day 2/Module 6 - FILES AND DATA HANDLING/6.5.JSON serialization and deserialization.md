## 5. JSON Serialization and Deserialization

### What is JSON?
**JSON** (JavaScript Object Notation) is a text format for storing and sending structured data. It looks almost exactly like a Python dictionary, and it is used by almost every website, app and API.

```json
{
    "name": "Asha",
    "age": 21,
    "skills": ["Python", "SQL"],
    "is_student": true
}
```

Real-life example: a **standard application form** that everyone can read, whether they use paper or a computer. JSON is the common language between different programs.

### Two directions
- **Serialization:** Python object → JSON text (writing, sending)
- **Deserialization:** JSON text → Python object (reading, receiving)

In short: **dump** writes JSON, and **load** reads JSON. The `s` in `dumps` and `loads` means "string".

Serialization (Python to JSON):
- `json.dumps(obj)` returns a JSON **string**
- `json.dump(obj, file)` writes JSON **into a file**

Deserialization (JSON to Python):
- `json.loads(text)` reads a JSON **string**
- `json.load(file)` reads JSON **from a file**

### Converting to a JSON string
```python
import json

student = {"name": "Asha", "age": 21, "skills": ["Python", "SQL"], "active": True}

text = json.dumps(student)
print(text)
# {"name": "Asha", "age": 21, "skills": ["Python", "SQL"], "active": true}
```
Notice the changes: Python's `True` becomes JSON's `true`, and Python's `None` becomes `null`.

### Pretty printing
```python
print(json.dumps(student, indent=4))
```
```
{
    "name": "Asha",
    "age": 21,
    ...
}
```
`sort_keys=True` sorts the keys alphabetically:
```python
print(json.dumps(student, indent=4, sort_keys=True))
```

### Converting back to Python
```python
text = '{"name": "Ravi", "marks": [80, 90]}'
data = json.loads(text)

print(data["name"])        # Ravi
print(data["marks"][1])    # 90
print(type(data))          # <class 'dict'>
```

### Saving to and loading from a file
```python
import json

student = {"name": "Asha", "age": 21}

# save
with open("student.json", "w", encoding="utf-8") as f:
    json.dump(student, f, indent=4)

# load
with open("student.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

print(loaded["name"])      # Asha
```

### What can and cannot be converted?
JSON supports only: **dict, list, str, int, float, bool and None**. Tuples are turned into lists, and sets and custom objects are not supported.

```python
json.dumps({1, 2, 3})      # TypeError: Object of type set is not JSON serializable
```

> **Note on keys:** JSON keys must be strings. A Python dictionary with integer keys like `{1: "a"}` becomes `{"1": "a"}` after conversion.

### Real-time example: a saved shopping cart
```python
import json
from pathlib import Path

cart_file = Path("cart.json")

if cart_file.exists():
    cart = json.loads(cart_file.read_text(encoding="utf-8"))
else:
    cart = {"items": []}

cart["items"].append({"item": "Milk", "price": 25})
cart_file.write_text(json.dumps(cart, indent=2), encoding="utf-8")

print("Items in cart:", len(cart["items"]))
```
Every time you run this, the cart remembers the old items. This is how many simple apps store data.
