## 7. `datetime`, `date`, `time` and `timedelta`

### Why do we need dates?
Dates appear everywhere: birthdays, bills, attendance, deadlines and logs. Doing date maths by hand (like "how many days from 15 Jan to 3 Mar?") is very error-prone. Python's `datetime` module handles it correctly, including leap years.

```python
from datetime import date, time, datetime, timedelta
```

### `date`: only the day
```python
from datetime import date

today = date.today()
print(today)                       # e.g. 2026-11-17
print(today.year, today.month, today.day)

birthday = date(1999, 8, 15)       # year, month, day
print(birthday)                    # 1999-08-15
```

### `time`: only the time of day
```python
from datetime import time

meeting = time(14, 30)             # 2:30 PM
print(meeting)                     # 14:30:00
print(meeting.hour, meeting.minute)
```

### `datetime`: date and time together
```python
from datetime import datetime

now = datetime.now()
print(now)                         # e.g. 2026-11-17 10:24:53.123456
print(now.hour, now.minute)

course_start = datetime(2026, 1, 15, 9, 0)   # year, month, day, hour, minute
print(course_start)                # 2026-01-15 09:00:00
```

### `timedelta`: a difference or duration
A `timedelta` represents a **span of time**: days, hours, minutes and so on.

```python
from datetime import date, timedelta

today = date(2026, 1, 15)
next_week = today + timedelta(days=7)
print(next_week)                   # 2026-01-22

yesterday = today - timedelta(days=1)
print(yesterday)                   # 2026-01-14
```

### Subtracting two dates gives a timedelta
```python
from datetime import date

start = date(2026, 1, 15)
end = date(2026, 3, 3)

gap = end - start
print(gap)            # 47 days, 0:00:00
print(gap.days)       # 47
```

### More timedelta options
```python
from datetime import timedelta

t = timedelta(hours=2, minutes=30)
print(t)                       # 2:30:00
print(t.total_seconds())       # 9000.0
```

### Comparing dates
```python
from datetime import date

deadline = date(2026, 12, 31)
today = date.today()

if today < deadline:
    print("Still time left")
else:
    print("Deadline has passed")
```

### Real-time example: days until a course ends
```python
from datetime import date

course_end = date(2027, 3, 31)
days_left = (course_end - date.today()).days
print(f"{days_left} days left in the course")
```

### Real-time example: age calculator
```python
from datetime import date

def calculate_age(birth_date):
    today = date.today()
    age = today.year - birth_date.year
    # subtract 1 if this year's birthday has not come yet
    if (today.month, today.day) < (birth_date.month, birth_date.day):
        age -= 1
    return age

print(calculate_age(date(1999, 8, 15)))
```
