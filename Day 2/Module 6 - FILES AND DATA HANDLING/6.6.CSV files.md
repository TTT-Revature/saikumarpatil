## 6. CSV Files

### What is CSV?
**CSV** (Comma-Separated Values) is a plain-text table. Each line is a row, and commas separate the columns. Excel and Google Sheets can open CSV files directly.

```csv
name,age,city
Asha,21,Chennai
Ravi,22,Mumbai
Meena,20,Delhi
```

### Reading CSV with the `csv` module
```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```
```
['name', 'age', 'city']
['Asha', '21', 'Chennai']
['Ravi', '22', 'Mumbai']
['Meena', '20', 'Delhi']
```
Each row is a **list of strings**. Remember that numbers like `21` are still text, so convert them with `int()` if you need to calculate.

Always use `newline=""` when opening CSV files. It stops extra blank lines appearing on Windows.

### Skipping the header
```python
with open("students.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    next(reader)                  # skip the header row
    for row in reader:
        print(row[0], "is", row[1])
```

### Writing CSV
```python
import csv

rows = [
    ["name", "marks"],
    ["Asha", 85],
    ["Ravi", 72],
]

with open("marks.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(rows)
```

### DictReader and DictWriter (easier to read)
These work with **dictionaries**, so you can use column names instead of positions.

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["name"], "lives in", row["city"])
```

```python
import csv

students = [
    {"name": "Asha", "age": 21},
    {"name": "Ravi", "age": 22},
]

with open("out.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "age"])
    writer.writeheader()          # writes the column names
    writer.writerows(students)
```

### Real-time example: total sales from a CSV
```python
import csv

total = 0
with open("sales.csv", "r", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        total += float(row["amount"])

print(f"Total sales: Rs.{total:,.2f}")
```

> **Watch out:** If a value contains a comma, such as `"Chennai, Tamil Nadu"`, the `csv` module adds quotes automatically. Don't split CSV lines manually with `.split(",")`, because it breaks on such values.
