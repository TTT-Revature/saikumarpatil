## 9. Assertions 

### What is an `assert`?
An `assert` checks that a condition is **True**. If it is False, Python raises an `AssertionError`. Assertions are mainly used by programmers to check their **own assumptions** during development.

```python
x = 10
assert x > 0          # passes silently
assert x < 0          # AssertionError
```

### Adding a message
```python
def divide(a, b):
    assert b != 0, "Divisor must not be zero"
    return a / b

divide(10, 0)        # AssertionError: Divisor must not be zero
```

### Assert vs raise
- Use **`assert`** for "this should never happen" checks while developing and testing.
- Use **`raise`** for checks that must **always** happen, such as checking user input.

Important: Python can run with optimisation (`python -O`), which **removes all assert statements**. So never rely on `assert` to check user input or security.

### Real-time example: checking a result while testing
```python
def average(marks):
    assert len(marks) > 0, "The list must not be empty"
    return sum(marks) / len(marks)

print(average([80, 90]))       # 85.0
```
