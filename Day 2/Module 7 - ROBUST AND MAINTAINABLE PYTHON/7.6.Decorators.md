## 6. Decorators 

### What is a decorator?
A **decorator** is a function that **wraps another function** to add extra behaviour, without changing the original function's code.

Real-life example: a **gift wrapper** at a shop. The gift (the original function) stays the same inside. The wrapper adds something extra around it, such as a bow or a message.

### A simple decorator, step by step
```python
def shout_decorator(func):              # receives the original function
    def wrapper():                      # the new function with extra behaviour
        print("Before the function")
        func()                          # call the original function
        print("After the function")
    return wrapper                      # return the wrapped version

def say_hello():
    print("Hello!")

say_hello = shout_decorator(say_hello)  # wrap it manually
say_hello()
```
```
Before the function
Hello!
After the function
```

### The `@` shortcut
The `@decorator_name` line above a function does the same thing as `func = decorator(func)`.

```python
@shout_decorator
def say_hello():
    print("Hello!")

say_hello()
```

### Decorators for functions with arguments
Use `*args` and `**kwargs` (from Module 5) so the wrapper works with any function.

```python
def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__} with {args} {kwargs}")
        result = func(*args, **kwargs)
        print(f"{func.__name__} returned {result}")
        return result
    return wrapper

@log_call
def add(a, b):
    return a + b

add(3, 4)
```
```
Calling add with (3, 4) {}
add returned 7
```

### Keeping the original name and docstring: `functools.wraps`
Without extra care, the wrapped function loses its name and docstring. Use `@wraps` to keep them.

```python
from functools import wraps

def log_call(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def add(a, b):
    """Add two numbers."""
    return a + b

print(add.__name__)     # add     (without @wraps it would say 'wrapper')
print(add.__doc__)      # Add two numbers.
```

### Real-time example: timing a function
```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        end = time.perf_counter()
        print(f"{func.__name__} took {end - start:.4f} seconds")
        return result
    return wrapper

@timer
def slow_sum(n):
    return sum(range(n))

print(slow_sum(1_000_000))
```

### Real-time example: a simple access check
```python
def admin_only(func):
    @wraps(func)
    def wrapper(user, *args, **kwargs):
        if user != "admin":
            print("Access denied")
            return None
        return func(user, *args, **kwargs)
    return wrapper

@admin_only
def delete_records(user):
    print("Records deleted")

delete_records("guest")      # Access denied
delete_records("admin")      # Records deleted
```

> **Trainer tip:** Students often find decorators confusing. Show the three-step version first (define, wrap, return), then the `@` shortcut. Stress that the decorator runs **once** at definition time, while the `wrapper` runs **every time** the function is called.
