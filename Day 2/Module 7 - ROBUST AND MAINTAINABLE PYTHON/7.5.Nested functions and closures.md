## 5. Nested Functions and Closures 

### Functions inside functions
In Python, you can define a function **inside another function**. The inner function is only visible inside the outer one.

```python
def outer():
    print("Outer starts")

    def inner():
        print("Inner runs")

    inner()
    print("Outer ends")

outer()
```
```
Outer starts
Inner runs
Outer ends
```

Real-life example: a **kitchen inside a restaurant**. The kitchen (inner function) is used by the restaurant (outer function), and customers outside can't walk into it directly.

### What is a closure?
A **closure** happens when an inner function **remembers variables from the outer function**, even after the outer function has finished running.

```python
def make_greeter(greeting):
    def greet(name):
        return f"{greeting}, {name}!"
    return greet

hello = make_greeter("Hello")
good_morning = make_greeter("Good morning")

print(hello("Asha"))              # Hello, Asha!
print(good_morning("Ravi"))       # Good morning, Ravi!
```

`make_greeter` has already finished, but `hello` still remembers `greeting = "Hello"`. Each returned function keeps its own copy of the value.

Real-life example: a **personalised stamp**. The stamp is made once, with the name "Hello" carved in. Every time you use the stamp, it still remembers that word.

### Changing a remembered variable: `nonlocal`
If the inner function needs to **change** the outer variable, declare it with `nonlocal`.

```python
def make_counter():
    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment

counter = make_counter()
print(counter())     # 1
print(counter())     # 2
print(counter())     # 3
```

Note that `nonlocal` is different from `global`. `global` refers to module-level variables, while `nonlocal` refers to the nearest enclosing function's variable.

### Real-time example: a multiplier factory
```python
def multiplier(factor):
    def multiply(x):
        return x * factor
    return multiply

double = multiplier(2)
triple = multiplier(3)

print(double(10))    # 20
print(triple(10))    # 30
```
