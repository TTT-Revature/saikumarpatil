## 2. Attributes, Methods, `__init__` and `self`

### Attributes: the data
An **attribute** is a variable that belongs to an object. It stores information about that object.

### Methods: the actions
A **method** is a function that belongs to a class. It describes what the object can **do**.

```python
class Student:
    school = "Sunrise School"     # class attribute (shared by all students)

    def study(self):              # method
        print("Studying hard")
```

### `__init__`: the setup method
`__init__` is a special method that runs **automatically** when you create a new object. It is used to **set up the starting data** for the object. It is often called the **constructor**.

```python
class Student:
    def __init__(self, name, age):
        self.name = name          # instance attribute
        self.age = age

asha = Student("Asha", 21)
ravi = Student("Ravi", 22)

print(asha.name)      # Asha
print(ravi.age)       # 22
```

When you write `Student("Asha", 21)`, Python:
1. creates a new empty object
2. calls `__init__` on it, passing the object as `self`, plus `"Asha"` and `21`
3. returns the finished object

### What is `self`?
`self` refers to **the specific object that is calling the method**. It lets each object keep its own data.

```python
class Student:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print(f"Hi, I am {self.name}")

asha = Student("Asha")
ravi = Student("Ravi")

asha.introduce()      # Hi, I am Asha   (self is asha)
ravi.introduce()      # Hi, I am Ravi   (self is ravi)
```

Note these points about `self`:
- It is always the **first parameter** in a method.
- You don't pass it yourself when calling. Python does it for you: `asha.introduce()` is the same as `Student.introduce(asha)`.
- The name `self` is a convention. It must be the first parameter, but the name could technically be different. Always use `self` so other programmers understand your code.

### Instance attributes vs class attributes
- **Instance attributes** belong to one object (`self.name`). Each object has its own copy.
- **Class attributes** belong to the class and are shared by all objects (`school`).

```python
class Student:
    school = "Sunrise School"              # class attribute

    def __init__(self, name):
        self.name = name                   # instance attribute

asha = Student("Asha")
ravi = Student("Ravi")

print(asha.name, ravi.name)                # Asha Ravi  (different)
print(asha.school, ravi.school)            # Sunrise School Sunrise School  (shared)

Student.school = "Future Academy"          # change it once
print(asha.school)                         # Future Academy  (all students see the change)
```

### Adding and changing attributes
```python
asha.age = 21          # adds a new attribute to this one object
asha.name = "Asha K"   # changes the value
```

### Real-time example: a bank account
```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        print(f"{self.owner} deposited {amount}. Balance: {self.balance}")

    def withdraw(self, amount):
        if amount > self.balance:
            print("Insufficient balance")
        else:
            self.balance -= amount
            print(f"{self.owner} withdrew {amount}. Balance: {self.balance}")

asha_acc = BankAccount("Asha")
ravi_acc = BankAccount("Ravi", 500)

asha_acc.deposit(1000)     # Asha deposited 1000. Balance: 1000
ravi_acc.withdraw(200)     # Ravi withdrew 200. Balance: 300
```
