## 6. `super()`

### What is `super()`?
`super()` lets a child class **call the parent's version** of a method. It is most often used inside `__init__` so the child can reuse the parent's setup, and then add its own.

Real-life example: a **new employee** joining a company. First, the standard HR onboarding (the parent's setup) is done. Then the team adds the specific training for the role (the child's extra setup).

### Without `super()` (repeating code)
```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

class Manager(Employee):
    def __init__(self, name, salary, team_size):
        self.name = name              # repeated code
        self.salary = salary          # repeated code
        self.team_size = team_size
```

### With `super()` (reuse the parent)
```python
class Manager(Employee):
    def __init__(self, name, salary, team_size):
        super().__init__(name, salary)   # parent does name and salary
        self.team_size = team_size       # child adds its own detail

m = Manager("Meena", 90000, 8)
print(m.name, m.salary, m.team_size)     # Meena 90000 8
```

### Calling an overridden method through the parent
```python
class Employee:
    def describe(self):
        return f"Employee: {self.name}"

class Programmer(Employee):
    def __init__(self, name):
        self.name = name

    def describe(self):
        base = super().describe()             # get the parent's description
        return base + " (Programmer)"

print(Programmer("Asha").describe())          # Employee: Asha (Programmer)
```

### Multiple inheritance and `super()`
Python follows a clear order called the **Method Resolution Order (MRO)** to decide which parent's method to use. You can view it with `ClassName.__mro__`.

```python
class A:
    def hello(self):
        print("A")

class B(A):
    def hello(self):
        print("B")
        super().hello()

class C(A):
    def hello(self):
        print("C")
        super().hello()

class D(B, C):
    def hello(self):
        print("D")
        super().hello()

D().hello()
# D
# B
# C
# A
print(D.__mro__)
```

> **Trainer tip:** Always call `super().__init__(...)` in a child's `__init__` when the parent sets up important data. Forgetting it is one of the most common OOP bugs.
