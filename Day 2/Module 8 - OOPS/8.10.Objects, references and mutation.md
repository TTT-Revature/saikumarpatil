## 10. Objects, References and Mutation 

### Variables are labels, not boxes
In Python, a variable is a **name that points to an object**. It does not hold the object itself. Several names can point to the same object.

Real-life example: a **contact in your phone** can have two names saved, "Mom" and "Amma". There is still only one person. Changing that person's phone number changes it for both names.

```python
class Student:
    def __init__(self, name):
        self.name = name

a = Student("Asha")
b = a                       # b points to the SAME object

b.name = "Asha K"
print(a.name)               # Asha K  (a sees the change too)
print(a is b)               # True
```

### Mutation: changing an object in place
A **mutable** object can be changed directly. Because names share the object, changes are visible through every name.

```python
def rename(student):
    student.name = "Renamed"        # changes the ORIGINAL object

s = Student("Asha")
rename(s)
print(s.name)                       # Renamed
```

### Reassignment vs mutation
- **Mutation:** `b.name = "New"` changes the object that both names point to.
- **Reassignment:** `b = Student("New")` makes `b` point to a **new** object. `a` is not affected.

```python
a = Student("Asha")
b = a
b = Student("Ravi")       # b now points somewhere else
print(a.name)             # Asha  (unchanged)
```

### Immutable objects behave differently
For numbers and strings (immutable), `+=` creates a new object instead of changing the old one.
```python
x = 10
y = x
y += 5
print(x, y)               # 10 15
```

### Passing objects to functions
Python passes **the reference**, not a copy. So a function can change the caller's object, but it cannot make the caller's variable point to a different object.

```python
def try_reset(student):
    student = Student("New")      # only changes the local name
    
s = Student("Asha")
try_reset(s)
print(s.name)                     # Asha  (unchanged)
```

### Real-time example: a shared team roster
```python
class Team:
    def __init__(self, name):
        self.name = name
        self.members = []

    def add_member(self, person):
        self.members.append(person)

roster = []
dev_team = Team("Developers")
roster.append(dev_team)

roster[0].add_member("Asha")
print(dev_team.members)       # ['Asha']  (same object, so the change shows)
```
