## 4. Instance, Class and Static Methods 

Python has three kinds of methods, depending on what they need to access.

### A. Instance methods (the most common)
An instance method works with **one object's data**. It takes `self` as the first parameter.

```python
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def average(self):             # instance method
        return sum(self.marks) / len(self.marks)

asha = Student("Asha", [80, 90, 70])
print(asha.average())             # 80.0
```

### B. Class methods (work with the whole class)
A class method works with the **class itself**, not one object. It takes `cls` as the first parameter and is marked with `@classmethod`. Class methods are often used to create objects in special ways.

```python
class Student:
    school = "Sunrise School"

    def __init__(self, name):
        self.name = name

    @classmethod
    def change_school(cls, new_name):
        cls.school = new_name          # changes it for all students

    @classmethod
    def from_string(cls, text):        # alternative way to create a student
        name, = text.split(",")
        return cls(name.strip())

Student.change_school("Future Academy")
print(Student.school)                   # Future Academy

s = Student.from_string("Ravi")
print(s.name)                           # Ravi
```

### C. Static methods (utility functions that don't need the class or object)
A static method does **not** use `self` or `cls`. It is a normal function that is grouped inside the class because it is related to it. It is marked with `@staticmethod`.

```python
class MathHelper:
    @staticmethod
    def is_even(n):
        return n % 2 == 0

print(MathHelper.is_even(10))     # True
print(MathHelper.is_even(7))      # False
```

### Quick comparison
- **Instance method:** first parameter `self`. Uses or changes one object's data.
- **Class method:** first parameter `cls`, decorator `@classmethod`. Works with the class as a whole.
- **Static method:** no special first parameter, decorator `@staticmethod`. A helper function related to the class.

### Real-time example: a temperature converter
```python
class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    def to_fahrenheit(self):              # instance method (uses this object's data)
        return self.celsius * 9 / 5 + 32

    @classmethod
    def from_fahrenheit(cls, f):          # class method (creates an object)
        return cls((f - 32) * 5 / 9)

    @staticmethod
    def is_freezing(celsius):             # static method (general helper)
        return celsius <= 0

t = Temperature(25)
print(t.to_fahrenheit())                  # 77.0
print(Temperature.from_fahrenheit(212).celsius)   # 100.0
print(Temperature.is_freezing(-3))        # True
```
