## 5. Inheritance and Method Overriding

### What is inheritance?
**Inheritance** is a way of creating a **new class from an existing class**. The new class (the **child** or **derived** class) gets all the attributes and methods of the existing class (the **parent** or **base** class), and can add its own.

Real-life example: a **Programmer** is a kind of **Employee**. A programmer has everything an employee has (name, salary, joining date) and also has programming skills.

This is the **reuse** part of OOP: write the common code once in the parent, and only write what is different in the child.

### Syntax
```python
class Employee:                       # base class (parent)
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

class Programmer(Employee):           # derived class (child) inherits from Employee
    pass

p = Programmer("Asha", 50000)
print(p.name)         # Asha   (inherited from Employee)
print(p.salary)       # 50000  (inherited from Employee)
```

Everything in `Employee` is available in `Programmer`, even though we wrote nothing inside `Programmer` itself.

### Adding new features in the child
```python
class Programmer(Employee):
    def __init__(self, name, salary, language):
        super().__init__(name, salary)      # reuse the parent's setup
        self.language = language            # child-only attribute

    def code(self):
        print(f"{self.name} is coding in {self.language}")

p = Programmer("Asha", 50000, "Python")
p.code()              # Asha is coding in Python
```
`super()` is explained in Section 6.

### Types of inheritance

The three main types are:

**1. Single inheritance:** a child class inherits from **one** parent class.
```
Base  →  Derived
(parent)   (child)
```
```python
class Base:
    def hello(self):
        print("Hello from Base")

class Derived(Base):
    pass

Derived().hello()     # Hello from Base
```

**2. Multiple inheritance:** a child class inherits from **more than one** parent class.
```
Parent 1      Parent 2
      \        /
        Child
```
```python
class Parent1:
    def skill_a(self):
        print("Skill from Parent 1")

class Parent2:
    def skill_b(self):
        print("Skill from Parent 2")

class Child(Parent1, Parent2):
    pass

c = Child()
c.skill_a()           # Skill from Parent 1
c.skill_b()           # Skill from Parent 2
```

**3. Multilevel inheritance:** a child class becomes a **parent** for another child class. It forms a chain.
```
Parent
  ↓
Child 1
  ↓
Child 2
```
```python
class Grandparent:
    def family(self):
        print("Family name: Kumar")

class Parent(Grandparent):
    pass

class Child(Parent):
    pass

Child().family()      # Family name: Kumar  (inherited through the chain)
```

### Method overriding
**Method overriding** happens when the child class **provides its own version** of a method that the parent already has. The child's version is used for child objects.

```python
class Employee:
    def work(self):
        print("Employee is working")

class Programmer(Employee):
    def work(self):                       # overrides the parent's method
        print("Programmer is writing code")

class Designer(Employee):
    def work(self):
        print("Designer is creating layouts")

Employee().work()      # Employee is working
Programmer().work()    # Programmer is writing code
Designer().work()      # Designer is creating layouts
```

### Checking inheritance
```python
print(issubclass(Programmer, Employee))     # True
print(isinstance(Programmer("A", 1, "Python"), Employee))   # True
```

### Real-time example: different kinds of accounts
```python
class Account:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def monthly_interest(self):
        return 0

class SavingsAccount(Account):
    def monthly_interest(self):           # overrides: savings earn interest
        return self.balance * 0.04 / 12

class CurrentAccount(Account):
    pass                                  # uses the default (no interest)

s = SavingsAccount("Asha", 100000)
c = CurrentAccount("Ravi", 100000)

print(round(s.monthly_interest(), 2))     # 333.33
print(c.monthly_interest())               # 0
```
