## 9. Dataclasses

### The problem: lots of boring code
Simple classes that only store data need a lot of repeated code: `__init__`, `__repr__` and `__eq__`.

```python
class Book:
    def __init__(self, title, author, pages):
        self.title = title
        self.author = author
        self.pages = pages

    def __repr__(self):
        return f"Book(title={self.title!r}, author={self.author!r}, pages={self.pages})"

    def __eq__(self, other):
        return (self.title, self.author, self.pages) == (other.title, other.author, other.pages)
```

### The solution: `@dataclass`
The `dataclass` decorator (from the `dataclasses` module) writes these methods for you, based on the fields you declare.

```python
from dataclasses import dataclass

@dataclass
class Book:
    title: str
    author: str
    pages: int

b1 = Book("Python Basics", "Asha", 250)
b2 = Book("Python Basics", "Asha", 250)

print(b1)              # Book(title='Python Basics', author='Asha', pages=250)
print(b1 == b2)        # True  (equality written automatically)
```

Notice the **type hints** (`str`, `int`) from Module 5. Dataclasses use them to know which fields to create.

### Default values
```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    age: int = 18            # default value
    city: str = "Chennai"

s = Student("Asha")
print(s)                     # Student(name='Asha', age=18, city='Chennai')
```

### Dataclasses with methods
You can still add your own methods.
```python
from dataclasses import dataclass

@dataclass
class Rectangle:
    length: float
    width: float

    def area(self) -> float:
        return self.length * self.width

r = Rectangle(4, 5)
print(r.area())        # 20
```

### Frozen (read-only) dataclasses
```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Coordinates:
    lat: float
    lon: float

c = Coordinates(13.08, 80.27)
# c.lat = 14.0       # FrozenInstanceError: cannot assign to a frozen instance
```

Frozen dataclasses are immutable, like tuples (Module 4), which makes them safe to use as dictionary keys.

### When to use a dataclass
- The class mostly **stores data** (records, settings, results).
- You want automatic `__repr__` and `__eq__`.
- Use a normal class when the object has complicated behaviour.
