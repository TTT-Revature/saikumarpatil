## 7. `async` and `await` 

### A new way to wait
Threads are not the only way to handle waiting. **Asynchronous programming** lets a single thread switch to another task whenever the current task would wait. This is very efficient for I/O-bound work, because thousands of waiting tasks can share one thread.

Real-life comparison: a **waiter in a restaurant**. Instead of standing at the kitchen door until one order is ready, the waiter takes new orders from other tables while the kitchen works. The waiter never sits idle, and one person serves many tables.

### `async def`: a coroutine
A function defined with `async def` is a **coroutine**. Calling it does not run it straight away. It returns a coroutine object that must be run by an event loop.

```python
async def say_hi():
    print("Hi")

coro = say_hi()          # nothing printed yet
print(type(coro))        # <class 'coroutine'>
```

### `await`: wait without blocking
`await` pauses the current coroutine until the awaited task finishes, and lets **other coroutines run in the meantime**.

```python
import asyncio

async def fetch_data():
    await asyncio.sleep(1)      # non-blocking wait (other tasks can run)
    return "data"

async def main():
    result = await fetch_data()
    print(result)

asyncio.run(main())
```

> **Key difference:** `time.sleep(1)` **blocks** the whole program. `await asyncio.sleep(1)` pauses only the current coroutine.

### Rules for `await`
- You can only use `await` inside an `async def` function.
- You can only await something that is awaitable (a coroutine, a task or a future).
- Regular functions cannot call `await` directly.

### How coroutines take turns
```mermaid
sequenceDiagram
    participant Loop as Event loop
    participant A as Task A
    participant B as Task B
    Loop->>A: run until await
    A-->>Loop: waiting for network
    Loop->>B: run until await
    B-->>Loop: waiting for disk
    Loop->>A: network ready, continue
    A-->>Loop: finished
    Loop->>B: disk ready, continue
    B-->>Loop: finished
```

### Real-time example: a restaurant order system
```python
import asyncio

async def prepare(dish, seconds):
    print(f"Started {dish}")
    await asyncio.sleep(seconds)     # kitchen cooking time
    print(f"Ready: {dish}")

async def main():
    await prepare("Dosa", 2)
    await prepare("Coffee", 1)

asyncio.run(main())
```
Here the two dishes are prepared **one after another**, because each `await` finishes before the next starts. Next we'll see how to run them together.
